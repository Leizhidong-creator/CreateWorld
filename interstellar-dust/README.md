# 尘埃之外 · 双场景像素剧情游戏

依据用户提供的《星际穿越》开篇梗概制作的 5–8 分钟单人探索小游戏。基于旧版 Pixel Story Kit 的引擎制作；旧 kit 独立目录已从仓库移除，来源与许可记录保留在本目录 `provenance/` 和 `LICENSE-NOTICE.txt`。没有 CDN、构建或 npm 依赖下载。

## 运行

需要 Node.js 20 或更新版本。在此目录运行：

```sh
npm start
```

打开终端显示的地址（默认 http://127.0.0.1:4173）。端口占用可运行 `npm start -- --port 4186`。macOS 也可双击 `开始游戏.command`。不要直接双击 index.html；ES 模块需要 HTTP 服务。

## 两个场景

- **大场景：地球 · 尘土中的家园**（1280×720 世界坐标）。跟随镜头，农舍、机棚、干枯玉米田、NASA 基地外围与皮卡。
- **小场景：家 · 墨菲的房间**（640×360）。固定镜头，书架、沙尘纹路、笔记本与墨菲。

为严格控制成两个场景，NASA 会谈安排在基地门外，离开地球用结局文字收束。地图压缩了农场至基地的距离，不代表电影中的实际地理。没有增加第三个室内或飞船场景。

## 操作

WASD / 方向键移动；E / 空格交互；M 地图；I 物品与线索；J 成就；Esc / P 暂停。手机请横屏，使用左下摇杆和右下情境按钮。对话先补全本句，再推进下一句。

当前目标只显示一条；地图指向区域或可达出口。剧情节点与探索进度自动保存在当前浏览器。暂停菜单可调音乐、音效、返回标题和确认清除本游戏记录。

## 主线提示（含剧透）

检查西南玉米田东缘 → 回农舍 → 调查书架 → 观察房间中央沙纹 → 书桌记录坐标 → 东北基地找布兰德（两次交谈） → 回家与墨菲告别 → 东南皮卡出发。告别、解读、出发均可暂缓并再次尝试。三个探索成就不影响结局。

## 项目文件

- `content.js`：完整对白、任务、物品、线索、交互条件和场景几何。
- `main.js`：调用原 createGame；通过原 hooks 加沙尘、纹路、地标牌。
- `story.css`：游戏主题和响应式样式。
- `assets/earth/`、`assets/room/`：场景原图、红色碰撞覆盖图、几何 JSON、QA 报告。
- `assets/characters/`：character-generation 生成的库珀四方向四帧行走包，以及墨菲、布兰德的静态方向素材；具体 QA 状态见 `docs/CHARACTERS.zh-CN.md`。
- `src/render.js`、`src/validate.js`：支持可配置动画帧数、待机帧、帧时长与脚点，保留原三帧格式兼容。
- `tests/story.test.mjs`：新故事的主线、选择回退、存档、奖励与可达性测试。
- `docs/ADAPTATION.zh-CN.md`：改编范围和对白状态契约。
- `docs/VERIFICATION.zh-CN.md`：本游戏验证情况。
- `docs/KIT-README.md` 和 `KIT-VERIFICATION.zh-CN.md`：原始底座文档快照。

## 素材与边界

场景图为本次 AI 生成的解释性布局；人物已重新使用 character-generation 与公开剧照参考生成。参考照片未打包；来源链接、外观推断和生成提示词记录在人物文档。未使用电影原声或原台词。底座的合成环境音与操作音效继续用于原型，未制作电影配乐或人物配音。对话和选择依据用户梗概编写，未核对电影最终剪辑的精确时间。

碰撞 JSON 使用原图像素坐标；游戏使用 1280×720 / 640×360 坐标，按 x/y 比例映射。模型为脚点加引擎半径 7；透明碰撞对象与地图使用同一份 `geometry`。家具和建筑按不可进入的矩形占地处理。
