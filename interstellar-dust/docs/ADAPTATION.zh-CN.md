# 改编与对白契约

唯一剧情事实源：用户本轮提供的《星际穿越》开篇梗概。材料为故事梗概，不是剧本或成片；未声称完成电影核验。用户指定双场景优先于配套提示词的三至五场景默认值。

## 因果路径与交互

| 原梗概事实 | 游戏转化 | 状态结果 |
| --- | --- | --- |
| 沙尘暴、粮食危机威胁人类 | 田边检查枯叶；风沙持续可见 | crop、blight |
| 库珀与墨菲发现重力异常 | 先查书架，再观察沙尘 | books、dust、gravity |
| 根据坐标找到秘密基地 | 在笔记本确认两组数字，地图解锁东北区域 | coordinates → found |
| 布兰德说明灭绝危机和虫洞计划 | 在基地门口对话，取得飞行资料 | mission、wormhole、flight |
| 库珀离开家人，踏上旅途 | 回房告别；在皮卡处确认启程 | goodbye → departed → beyond |

原创游戏补充：玉米叶检查、书桌笔记本、星空画、机棚旧扳手、模型火箭、基地门口会谈与步行距离压缩。它们不是声称出现在电影里的细节。宽窄沙纹不提供真实地理坐标，不冒充电影具体数字。没有加入后续剧情的异常来源解释。

## 角色声音

- 库珀：由“前宇航员／父亲”的身份推导，先观察、质疑，再行动。句子短；对女儿不做无依据的归期保证。
- 墨菲：由共同发现异常和父女关系推导，用具体观察反驳成人解释；告别时表达不舍与反对，不被强写成欣然赞同。
- 布兰德：由科学家与任务倡议者身份推导，解释风险、提出需要，承认未知，不提前知道剧情之外的事实。

以上声音为梗概支持下的保守创作假设，不是逐场表演研究结论。

对白使用 narrative-npc-dialogue 的人物压力、回应关系、知识边界与五遍筛选流程，输出直接采用引擎 `lines / choices / onComplete` 格式。每句不超过 50 字；没有复制电影台词。

## 交互契约

`crop/books/dust/arrival/mission/promise` 的奖励在对白结束时结算，并使用 once 键。可重复交谈通过剧情条件改为状态对白。

`decode` 的暂缓选项不发坐标，重新交互即可确认；`goodbye` 的暂缓选项不修改告别状态；确认告别后播放 `promise`，完成后才给星空画。`depart` 的确认选项触发唯一结局。

所有八阶段任务有明确前置。物品和线索分开保存；飞行资料、画是物品，重力观察、坐标、虫洞是信息。三个可选发现不阻塞主线。

## 技能适用范围

采用 scene-generation 的几何优先、生成一次、依据图像校正几何、红色覆盖与确定性 QA 流程；采用 imagegen 生成两张解释性场景图；采用 narrative-npc-dialogue 写对白并接入状态。content-understanding 的事实／推断／玩法分离原则用于上表，没有单独交付完整影视结构档案。

未启动 art-direction 的三候选与真人盲测：用户已指定简单双场景像素游戏，配套文档已锁定视觉类型。本次按用户纠正，使用 character-generation 和带来源记录的公开剧照重新生成人物。库珀完整包通过验收；墨菲和布兰德完整行走包在一次定向补生成后仍未通过，保留失败记录，只接入独立检查通过的静止帧。详见 CHARACTERS.zh-CN.md。
