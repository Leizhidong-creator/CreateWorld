## 浏览器验证

对解压后的发行包启动独立本地服务器，通过正常界面完成：

1. 标题 → 新手引导 → 方向键移动 → 触控交互按钮离开小屋。
2. 庭院与 NPC 对话 → 领取钥匙 → 任务与物品同步更新。
3. 刷新页面 → 继续故事 → 恢复任务、位置与钥匙。
4. 钥匙开门进入档案室 → 调查信件 → 获得物品并切换目标。
5. 与档案员对话 → 记录信息线索 → 解锁成就，其他条目保持“未发现”。
6. 返回庭院 → 点亮信号灯 → 返回 NPC → 选择交付信件 → 两页结局 → 返回标题。
7. 重新开始 → 初始任务恢复；先前解锁的长期成就仍然保留。

开发目录中也检查了展开/收起地图、镜头跟随、靠近交互与静态碰撞。

第二题材“轨道余声”在 844×390 横屏视口下成功加载标题与新手引导，文字和按钮布局可读，并使用独立游戏存档 ID。完整端到端浏览器通关验证使用默认题材；第二题材配置合法性由自动检查覆盖。未声称完成真实手机硬件或所有浏览器的兼容性测试。双指操作生命周期通过模拟独立 pointerId 的行为测试验证。

小游戏容器通过自动化生命周期测试。tests/plugin-fixture.html 提供额外的人工验证入口，不是随包附带的具体小游戏。
