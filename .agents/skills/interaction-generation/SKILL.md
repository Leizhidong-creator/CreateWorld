# 可操作交互实现

读取机制规格、场景站位与统一状态，明确每个交互的对象、可见信息、前置条件、输入、结果和反馈。不能把未实现机制替换成一段成功文字。
探索使用移动与情境交互键。具体机制可使用点击、方向键或拖动；使用框架输入/暂停约定，不让弹窗穿透。机制可在场景内发生，也可挂载小游戏容器。
已有组件适合时复用，不适合时写项目extensions模块。绑定开始、成功、失败、取消、重试和销毁，清理监听器/计时器。一次性效果只在成功提交。
新增状态、动作或资源同步到权威定义与相关测试，不用DOM或动画状态代替世界状态。记录实际成功、条件不足、失败恢复、取消与重复操作轨迹。
只生成本次实现需要的配置和代码，避免重复长报告。真实键盘/点击/触屏验证，不通过观察接口直接设状态通关。

在 Create World 工作台内使用时，先按需读取 [项目接入约定](references/workbench-v2.md)。技能可在完整任务中重复调用，不规定固定流水线。旧格式参考仅用于对应旧项目，不能覆盖当前合同。
