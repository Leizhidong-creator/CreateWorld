# 固定界面风格统一

位于美术资产生成集合的统一美术规范之下。输入为上游完整剧情玩法与资产需求、已确定的美术规范及版本、主体资产参考和目标游戏工程。交付目标是目标游戏中实际生效的界面样式和必要素材，不能只输出风格建议或效果图。

## 复用共同风格

读取 [统一美术规范](../art-direction/SKILL.md) 和 [当前项目像素基线](../art-direction/references/stardew-pixel-profile.md)，复用已有配色、像素画法、材质与情绪，不重新选择风格，不将所有题材改成明亮农场。已通过的主体场景与角色用于核对协调性。

将世界视觉转成便于操作的平面界面：面板明暗、边框、像素阶梯、图标、强调色、字体表现及反馈应协调；不机械套用正交斜俯视、人物世界比例或场景光照造成字斜、字暗。16∶9约束游戏视窗，不强制图标或面板为16∶9；按实际显示、触控和文字需求定尺寸，不默认128×128。像素图形使用适合的清晰采样，文字保持真实排版和可读性，不为了颗粒效果强制最近邻处理字体。

## 功能边界

- 上游需求和原有功能只读。默认保留布局、快捷键、触控命中范围、焦点、模态隔离、移动与交互行为；只更改视觉表达。上游明确要求的布局适配才调整布局，并复查操作。
- 不新增彩蛋、任务或玩法，不泄露未发现内容，不改变地图的信息范围、标记含义或引导粒度。
- 地图、线索笔记、发现内容等可选功能按已有配置启用；视觉统一不等于每个游戏都要开启全部功能。未启用项标为不适用，不打开功能凑齐展示。
- 保持存档键、格式、版本、隔离、恢复、自动保存策略与剧情状态兼容；不通过新建存档或重置状态规避验证。
- 复用目标游戏现有UI组件，不另起一套按钮、对话、背包或存档系统，不重复显示相同控件。

## 全组件覆盖

按实际存在的组件和状态制定并落实样式，已不存在的状态不补造。按下、焦点、选中、禁用和未知等差异不能只依靠颜色，也用边框、标识、形态或文字保持可辨。

| 组件 | 必须处理的视觉与状态 | 不得改变 |
| --- | --- | --- |
| 摇杆 | 底座、摇杆头、静止、拖动与模态隐藏；装饰不得截断拖动区 | 移动向量、独立指针、释放归零和命中范围 |
| 交互按钮 | 常态、可交互、按住、禁用与情境文案 | 目标选择、触发、长按时机和键位 |
| 地图 | 小地图/展开地图的容器、实际Canvas配色、玩家/地标/任务/迷雾图例 | 坐标、可见信息、任务指向及开关 |
| 彩蛋发现与成就 | 已发现/未发现卡片、图标和实际通知提示 | 隐藏身份、触发条件、一次性奖励与持久记录 |
| 对话 | 面板、说话人、正文、继续与选项的可读层次和焦点 | 逐字播放、首次补全/再次推进及分支效果 |
| 背包与物品详情 | 图标、名称、数量、空态、详情、已启用线索笔记 | 获取、使用规则、数量和条件 |
| 存档／继续 | 标题的继续入口、保存反馈及已有异常提示 | 是否有可继续存档、兼容性与真实保存结果 |
| 暂停 | 面板、继续/保存/设置/返回操作及其已有子页 | 暂停恢复、声音设置和返回标题的原有行为 |

共享工具栏、焦点框、提示通知、帮助/设置等上述模块实际可达的界面一起核对，避免打开子页后退回另一套风格；不因此新增界面功能。

## 实际适配步骤

1. 读取目标工程并按 [源码映射与接入约束](references/runtime-mapping.md) 确认真正参与构建的运行时、样式、图形和Canvas。记录当前组件、开关、样式入口及共用美术版本，不凭文件名推断已接入。
2. 将美术规范映射为当前工程能使用的界面颜色、边框、字体、图标与状态样式。沿用已有主题配置和变量；CSS、现有SVG或程序绘制能表达的部分直接适配，需要额外装饰时才生成图片。保留原有语义标签和可访问名称，文字不烘焙进图片。新增装饰只属于界面制作衍生素材，不新增剧情资产。
3. 优先使用目标游戏现有主题配置、项目级样式和扩展机制，将选择器和变量限定在目标游戏根节点，不影响其他游戏或工作台。先核对构建打包、资源引用、加载顺序及内容安全策略，不能假定新CSS会自动加载。
4. 分别处理DOM/CSS、摇杆图形和Canvas地图；只改主色或面板不等于全部组件完成。现有接口不足时记录具体元素、原因、受影响范围及必要的最小适配；可在当前任务授权范围内完成项目级适配，涉及共用宿主变更则返回调用方安排，不能静默修改共享底座或伪称已支持。
5. 接入实际游戏构建，查看主体资产与界面同时出现时的效果，再验证各状态与操作。缺少可运行工程、必要样本状态或测试能力时，交付已完成部分并标明缺口，不编造截图和验收。

## 验证与交付

执行 [检查清单](references/verification.md)。在桌面和手机横屏下实际查看字体、遮挡、像素清晰度与触控区域；长中文、空背包、未发现内容、禁用交互和已有存档均按真实状态验证。遵循减少动态效果设置，不用高频闪烁表达状态。

交付已接入的样式/配置/必要素材、资源引用与版本记录、组件覆盖表、实际截图和检查结果。覆盖表区分已适配、未适配、不适用、待接口，并分别记录视觉与功能验证；未实际接入、播放或操作的项目明确标为未验证，不以静态截图代替功能通过。沿用项目现有记录结构，不强制新增运行时API或存档字段。

修复仅针对相关样式、素材和状态，不重做主体美术或修改玩法；图像生成按同一输入最多两轮有依据的局部修复，仍失败保留诊断。只有全部启用组件及必要验证完成时才报告完成；效果图、原始图形、接入成功、真实操作分别报告。
