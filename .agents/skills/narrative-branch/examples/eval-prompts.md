# 独立前向任务

1. 使用该技能为原创“停电医院”做分支：玩家是电工，只有一组电池，可先恢复手术室或电梯；第二处必须通过可选维修恢复，不允许凭空补电池。两路在屋顶汇合且救助顺序要在尾声保留。交付设计、bundle 与实际验证报告。只使用提供的状态和动作；缺口列为修订。
2. 为三章节侦探游戏设计延迟后果：第一章向证人承诺保密，第二章可用证词换取通行，第三章原作固定抓获凶手。允许玩家违约，但不新增真凶、不可让证人提前知道未公开事实。产物须解释汇合保留与固定结局下的选择价值。
3. 原作是一篇无反事实授权的送信短篇，用户要求忠实结局，仅希望加入“是否阅读旁人的信”的道德选择。分析是否应做完整多结局，生成最小合适产物与验证计划；不要为了技能名称强造三个结局。

评估者检查产物和因果，而不按措辞打分；这些提示本身不算已执行评测。
