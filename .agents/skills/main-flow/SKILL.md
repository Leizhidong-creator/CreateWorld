# 整部游戏流程

以整部游戏为目标连接事件、场景、机制和结局。明确节点进入条件、玩家行为和完成结果；跨场景共享状态，不生成互不相干的小网页。
自主选择整体或分段处理，不规定章节数、节点数或固定生产顺序。提前获取物品、重复交互、回访和失败恢复必须有合理结果。
引导、机制使用与组合应服务真实推进。必经节点承担信息、状态、目标、操作验证或必要叙事作用；没有作用的内容合并、删除或改可选。约10分钟是估计，不是字数配额。
暂停、地图、标题、设置、重开等采用框架已有生命周期，不重新设计一遍。保留关键节点ID与场景连接，新增依赖同步到状态和旅程。
以实际运行时规则检查流程；不能把无条件图连通当作条件可达。完整通关和中途恢复由真实输入证明。

在 Create World 工作台内使用时，先按需读取 [项目接入约定](references/workbench-v2.md)。技能可在完整任务中重复调用，不规定固定流水线。旧格式参考仅用于对应旧项目，不能覆盖当前合同。
