# 游戏整合与工程诊断

正式交付前核对 `design.json.artDirection` 与 [统一美术合成验收](../art-direction/references/visual-standard.md)。单场景也需实际运行截图中的角色、背景、家具共同通过视觉审阅；构建、碰撞和通关通过不能替代它。没有统一美术证据的临时资源不能作为正式成品交付。

读取当前框架和项目机制接口。常规配置合并、资源检查、静态构建和ZIP导出调用宿主程序，不写一份模型自报passed替代它。
整合项目extensions的注册、输入、状态、暂停、成功/失败/取消与清理。保持全局状态一致，修改依赖时重新验证受影响部分。
可以随时构建机制样例或临时素材版本解决不确定性，但最终目标始终是整部游戏。临时样例不能作为正式交付，正式资源替换后要再次测试。
工作台使用当前GameConfig与compiler，旧多界面按钮/单房间构建器退出本工作台生产路径。只在维护旧项目时使用其专用参考。
保留失败产物和已有可用版本；发布到外部平台不是本技能默认动作。导出包应有源码来源、启动说明，并在新目录独立验证。

在 Create World 工作台内使用时，先按需读取 [项目接入约定](references/workbench-v2.md)。技能可在完整任务中重复调用，不规定固定流水线。旧格式参考仅用于对应旧项目，不能覆盖当前合同。
