# 素材与内容边界审核

本项目允许正常剧情冲突、动作冒险、武打、危险情境和恋爱；禁止色情及过度血腥、残酷的呈现。这是项目内部制作尺度，不代表平台年龄评级。审核必须指出实际内容中的具体问题，不凭题材、关键词、武器、身体特征或无依据的联想阻断制作。

## 范围与判断依据

检查本次交付的图片、动作、对白、旁白、描述、相关音效及可操作互动。来源故事和参考是理解语境的材料：来源出现敏感情节，不等于必须详细展示，也不因此否定整部改编。版权、来源可信度、美术一致性和玩法完整性由原有职责负责，不扩展成本审核的门槛。

综合实际动作与对象、细节、构图重点、时长与重复、玩法作用和叙事语境判断，不机械计分：

- 提示词写“非色情”“非血腥”不能代替实际查看；像素风、遮挡、反派身份或“剧情需要”也不自动豁免。
- 正常战斗循环不是反复施虐。区分攻击仍在战斗的敌人，与折磨失去反抗能力的对象、主动延长其痛苦。
- 无血不等于没有残酷表达；无裸露不等于没有色情表达。反过来，红色像素不必然是血，身体曲线不必然是色情。
- 不设血液像素数、露肤比例、关键词命中等自动拦截阈值。普通角色没有填写年龄且内容不涉及性化时，不追加年龄核验。

## 可执行边界

| 内容 | 项目尺度 |
| --- | --- |
| 拳脚、刀剑对招、枪械、爆炸、格挡、击退、怪物攻击 | 允许正常动作与胜负表达；武器类型不是拦截理由，不要求改成玩具或机器人 |
| 倒地、昏迷、战败、死亡、墓地、非血腥遗体 | 允许表达结果，不细致展示肉体损伤和死亡痛苦 |
| 擦伤、淤青、少量血迹 | 允许作为伤势信息，不因出现血迹就返工 |
| 大量喷血、断肢、内脏、开放伤口特写 | 不通过；移除突出血腥与身体破坏的表现，保留必要事件和战斗结果 |
| 囚禁、审讯、战争、刑罚及侵害经历 | 允许严肃、简略交代事实与后果；不详细展示酷刑，不以折磨、羞辱或延长痛苦作为主要互动或奖励 |
| 恋爱、拥抱、普通亲吻 | 允许；不因亲密关系本身追问或拦截 |
| 泳装、运动装、赤膊、露肩露背、普通体型差异 | 结合情境正常通过，不按服装、露肤或身体特征单独判定色情 |
| 明确性行为、模拟性行为的动作、性器官聚焦、以性刺激为目的的姿势和镜头 | 不通过；穿着完整、像素化或遮挡仍可能明确表达色情 |
| 未成年人色情化、性侵害色情化或可操作化 | 不通过，不用改名、遮挡或降低清晰度规避 |
| 非色情的医疗、艺术或生活裸露 | 根据实际语境判断，不自动判色情；与本作无关或不适合当前呈现的，作为表达建议或需求问题说明，不虚报色情违规 |

“性侵害可操作化”指让玩家实施性侵害行为本身；不将逃脱、救援、保护受害者或表达创伤后果的正常剧情与玩法归入禁止项。

## 复用已有环节

以下是各环节的职责，不是新增的固定三轮审核。不得新增独立审核工具、模型调用、多代理复核或逐项人工审批。

1. **已有需求阅读与改编**：遇到明确越界要求或确有风险的片段时，确定表现方式，写入已有设计或任务说明。普通内容不增加安全声明。保留角色动机、关键事件与后果，不擅自删掉战斗或改结局。
2. **已有素材审图与文本检查**：看实际结果，连同美术、身份、动作检查一起判断。静态图使用已有原图/处理图；动作结合完整图集、帧序与已有播放预览，不凭站姿推断全动作，也不孤立解读中间帧。文字结合必要上下文；音效只在实际相关时听取片段。无需为普通素材新增放大图、录屏或报告。
3. **已有游戏审阅 `cw_review`**：复用运行截图、对白、实现与操作证据，检查组合、镜头、字幕、声音和循环是否改变表达，玩家互动是否产生单图看不到的问题。截图只证明对应时刻；已有证据确实不足以判断某个相关动作时，只补看该动作，不因此重做全部内容审查。

通过且未变化的内容复用已有结论；变更只复查受影响的表达与必要组合。继续沿用现有候选版本和证据关联、构建及验收失效规则，不新建哈希、签名、缓存或验收机制。不追溯重制旧可用版本。

## 结论、证据与处理

内容结论与检查状态分开：结论为“通过 / 需要调整 / 边界待定”，检查状态为“已检查 / 部分检查 / 未检查”。未查看、文件缺失或工具失败不能被写成色情/暴力违规，也不能推定通过。

- **通过**：在范围内正常继续，不需要用户确认。普通通过项按本批或本次实际查看范围写简短结论，不为每张素材建立声明。
- **需要调整**：指出对象ID、实际画面/帧/文本/交互证据、越界表现及局部建议。仅修相关内容；不受影响项继续。对生成偏差可按已定尺度修复，不改权威需求；改变明确需求、关键剧情或玩法时返回上游决策。
- **边界待定**：必须说明具体歧义及缺少的最少信息，不能只说“可能敏感”。先利用已有上下文；只有无法消除且实质影响内容边界或需求时才问用户。普通武打、少量血迹、正常亲吻、服装与无依据联想不触发确认。

记录使用现有素材 notes、视觉审阅 observations/issues/warnings，以及 `review.json` 的 issues/unverified；普通通过项可以写入已有 observations，游戏审阅可用简短 `contentReview` 摘要记录实际查看范围和结论，不强制逐资产表或独立文件。不修改确定性 QA 的检查项。

明确越界项作为需修复的问题令本次已有审阅 `passed=false`，不能降为普通美术建议；仅不适合当前作品的表达建议不要冒充违规。具体边界歧义或必要证据缺口写入 issues/unverified，并如实保持未解决，不能声称该内容通过；不能因泛泛的“没有证明所有内容绝对安全”阻断交付。内容问题不伪报为 `visualPassed=false` 或美术六项失败，游戏总通过仍按已有审阅结论表达。

修改后在原有返修流程复查相关问题，不插入额外审核轮次、不增加重试额度。复查仍失败先定位原因；需求冲突返回上游，不通过反复改措辞无限生图。提问应给具体对象、冲突和可选表达，不使用“作品包含暴力，是否继续”式笼统确认。

记录示例：

- 通过：“已查看本批角色图集及对战预览；包含刀剑对招、击退、倒地，符合普通战斗尺度。”不能据此声称未查看分支全部通过。
- 调整：“guard_attack 第4—6帧突出断肢与喷血；保留挥剑、受击、倒地，移除肢解与喷血。”
- 未检查：“相关动作预览未能读取，现有站姿截图不能判断该动作。”这不是违规事实。

## 边界校准案例

以下用于规则维护和疑难案例比对，不是每次生成必须重跑的测试清单。

| 案例 | 预期判断 |
| --- | --- |
| 持剑交手、火花、一人倒地；连续攻击仍在战斗的怪物 | 通过 |
| 手臂少量血迹；战争废墟、墓地、覆布遗体 | 通过 |
| 成人泳装、赤膊训练、普通身材曲线 | 通过 |
| 正常恋爱拥抱、普通亲吻；严肃简述侵害经历 | 通过 |
| 红衣角色倒地，无其他伤口依据 | 不凭红色判流血或违规 |
| 无血但长时间展示折磨痛苦；反复折磨失去反抗能力者领奖 | 需要调整 |
| 动画突出断肢、内脏与喷血 | 需要调整 |
| 衣着完整但明确模拟性行为；未成年人色情化 | 不通过 |
| 非色情医疗裸露 | 按语境及本作需求判断，不自动判色情 |
| 图片缺失或只看过站姿、尚未查看相关动作 | 对缺失范围记未检查，不猜测违规或通过 |
