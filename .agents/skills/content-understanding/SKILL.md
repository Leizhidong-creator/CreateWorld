# 原作理解与证据

阅读实际材料，区分原作事实、推断与原创补充。作品版本不同不得混用；不把模型记忆当检索记录。用户已授权作品名改编时可直接检索，不重复申请联网。
建立紧凑的来源、关键事件、动机、因果与结局档案。可以按问题检索或增量读取长材料，但明确已读范围。无需给每个节点填写玩法提示，也不按固定比例压缩主干。
缺失过渡可按任务授权原创并标记；核心动机、因果或结局无法核实时记录具体缺口。只有会影响正确交付的问题才询问用户。
工作台采用 source.json；结构见本项目制作契约。独立分析需要出版物结构档案时再读 references/method.md 与 references/schema.md，旧YAML不是工作台必经格式。

在 Create World 工作台内使用时，先按需读取 [项目接入约定](references/workbench-v2.md)。技能可在完整任务中重复调用，不规定固定流水线。旧格式参考仅用于对应旧项目，不能覆盖当前合同。
