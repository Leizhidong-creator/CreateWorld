# 统一游戏状态

世界状态、制作任务进度、Codex会话是不同对象。为本作定义变量含义、初值、读写者、生命周期和保存需求，避免每个场景私藏剧情变量。
条件读旧状态，效果原子提交，成功才记录once和派发反馈。失败、取消、重复和重试不能重复领奖或留下半完成结果。可派生的信息不重复保存。
使用当前框架的类型、事务和可达性工具，不另造语义不同的模拟器。临时小游戏状态可局部维护，最终结果必须统一提交。自定义机制无法静态证明时明确范围，要求实际操作检查。
局部修改检查读写依赖。兼容存档继续使用，不兼容保留旧版本/旧存档并明确需要新局，不静默清空。
只维护权威状态定义与必要说明；旧bundle校验器只用于旧项目，不是本工作台必经步骤。

在 Create World 工作台内使用时，先按需读取 [项目接入约定](references/workbench-v2.md)。技能可在完整任务中重复调用，不规定固定流水线。旧格式参考仅用于对应旧项目，不能覆盖当前合同。
