# 工作台接入

本技能属于美术资产生产层。上游已完成完整剧情、玩法和详细资产清单；本技能只执行分配的美术任务，不自主新增场景、角色、道具、动作或玩法。整部游戏的时长、场景数量与剧情改编由上游负责，不能转化成本技能扩充资产的依据。

宿主提供当前需求包、资产ID、固定约束、框架文档与工具。source.json作为来源证据，design.json中的既定剧情玩法及资产清单只读；仅在指定位置补充美术和制作数据。game.json或game.project.json+parts及journeys.json中的玩法与路线不因视觉制作而擅自改写。

按需使用cw_read_skill和cw_assets等宿主工具，范围限定在本次分配的清单。构建、真实操作与整体验收由调用方组织；素材产出或模型自报不能替代实际验证，cw_finish的整体验收不属于单项素材交付承诺。

发现需求缺失、矛盾、工具能力不足或必须变更清单时，返回带资产ID的问题与建议，由上游更新需求包后继续；可继续不受影响项。不得补写剧情过渡、修改关键效果或静默扩充资产。只改本次获准资产与制作数据，不改宿主或全局设置；失败不覆盖已接受版本。
