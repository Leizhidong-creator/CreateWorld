# 星露谷式像素画法、固定视角与剧本尺度

本项目共用美术基线，适用于角色、场景、道具与动作。保持星露谷式像素语言与固定视角；空间尺度依据本次剧本及用户具体要求规划。后续用户明确要求优先，不扩展为其他项目全局规则。

## 尺度规划与制作合同

- 不规定人物占场景、视窗或屏幕的固定比例，不规定所有人物一格宽两格高，不强制所有角色同高。人物与建筑、家具、道具、其他人物之间的大小关系由剧本、世界设定和具体要求决定。小人国、巨人、大小人物共处、体型变化均保留指定差异。
- 16×32人物、16×16地块仅作为《星露谷物语》原作的像素密度参考，不是所有剧本的强制导出尺寸或世界比例。保留简化五官、清晰轮廓、少量服装色块与克制细节密度，不将人物画成写实高精度设定稿。不用强制同尺寸破坏剧本中的体型关系。
- 制作前消费已有尺度设定；未细定时，根据剧本及用户要求补全美术制作参数：人物间相对体型、人物与关键环境及道具的相对大小、各角色逻辑尺寸、地块尺寸、视窗范围、显示倍率、脚点与操作站位。记录依据，不新增变身或大小变化玩法。信息不足且会改变世界设定时询问关键缺项，不擅自套用普通人尺度。
- 对象归属决定尺度：小人的房屋可适配小人，人类的杯子可远大于小人；门、床和工具不必都适合玩家使用。核对需求指定的可通过、可握持、可攀爬等关系，不能为了套固定比例修改剧情或交互。
- 同一场景采用自洽的世界单位到逻辑像素映射，保持像素颗粒协调；这不意味着不同体型资产相同尺寸。同一角色、同一形态跨动作保持已确定身体尺度，画布留白与工具伸展单独记录，不通过缩小人物塞进单元格。剧本指定体型变化时按形态记录，不能当作漂移修掉。
- 原生生成母版保留，另按本次确定的逻辑尺寸导出透明运行时精灵，在1倍尺寸读图；展示版仅用最近邻整数倍放大。原生图尺寸、逻辑尺寸、主体大小、动作留白与显示尺寸分别记录，不默认128×128。机械缩小写实人物不算像素画法达标。
- 游戏视窗仍为16∶9，逻辑视窗和世界范围按场景需求确定，不跨剧本固定分辨率或人物占屏比。不同场景的取景范围或显示倍率可按规划变化，保留映射记录，不能任意分别缩放人物和背景造成关系失真。滚动地图本身不必16∶9。

## 固定视角与画法

- “2.5D／3渲2”在本项目表达空间层次目标：星露谷式二维像素地图，固定正交斜俯视，可见物件顶面与朝向玩家的正面。左右地图轴水平、前后轴竖直，平行线不汇聚，无地平线、消失点或近大远小。禁止等距菱形地图、45度旋转地图、纯顶视、低机位正视、广角透视及写实3D材质。不要单独用“3渲2”代替具体约束。
- 所有室内外场景锁定相同投影与俯视程度；取景范围变化不等于改变投影。首张审阅通过的场景作为视角基准，后续生成实际引用；原作剧照控制内容与身份，不覆盖视角。固定视角不等于固定人物占屏大小或统一世界尺寸。
- 用硬边像素色块、离散明暗与前后遮挡表现体积，按脚点/接地点组织遮挡。保持剧本的材质本色与光照情绪，不把所有故事改成明亮农场。背景不烘焙人物，前景层归属明确。

## 可复用生成提示词

调用时加入本次资产说明、尺度规划、逻辑尺寸与必要参考，不只写作品名称。

### 人物

生成指定人物地图精灵，采用《星露谷物语》式简洁像素语言与细节密度，以少量清晰色块表现头发、五官和服装。人物体型、逻辑尺寸及其与场景、其他人物和道具的大小关系严格依据本次剧本及尺度说明，不固定占屏比，不强制16×32或所有角色同高。实际引用身份母版，保持发型、服装、身体侧别及当前形态比例；三视图沿用同一地图视角。在实际逻辑尺寸下身份可辨，完整轮廓入格，透明背景，无光晕、文字或棋盘底纹。保留原生母版，按确定尺寸另导出精灵，展示仅作最近邻整数倍放大。避免写实人体设定稿、微纹理、平滑渐变和软边。

### 场景

生成指定场景的16∶9游戏背景，采用星露谷式二维像素空间表达。严格沿用视角基准的正交斜俯视，左右轴水平、前后轴竖直，可见物件顶面和正面，平行边不汇聚。根据本次剧本和尺度规划确定地块、建筑、家具与人物的相对大小及取景范围；不规定人物必须一格宽两格高或占屏固定比例。小人国、巨物环境与混合体型保留指定尺度差异，不强制家具适合普通人。交互留白和站位适配指定角色及操作关系。以硬边像素色块、离散明暗和遮挡表现2.5D体积，保持指定布局与氛围，不添加人物或UI。禁止等距菱形、地图旋转、地平线、广角透视、纯顶视、电影正视、照片纹理和写实3D材质。按规划的逻辑视窗与显示倍率输出，保留母版。

### 道具与特殊动作

沿用本次剧本规划的角色、道具与场景尺度及固定斜俯视。道具以少量材质色块与可辨认轮廓表达；与手掌的相对大小依据需求，不将巨物强制缩成普通手持工具。动作实际引用当前形态人物母版与道具基准，保持身体尺度与细节密度。按指定动作相位生成，支撑点稳定，动作伸展使用显式留白而不缩小人物。透明背景、无光晕、无文字，明确工具随人物绘制还是独立叠加。核对握持、支撑、接触和遮挡，按实际时序播放；未播放或未接入游戏的项目标记未验证。

## 验收与依据

按剧本指定尺度关系验收，不按统一人物占屏比验收。交付记录尺度依据、角色/形态逻辑尺寸、原生尺寸、地块单位、视窗及显示倍率、脚点、工具归属与视角参考。检查1倍轮廓、动作间体型、大小角色同场比例、关键通道与交互关系、跨场景视角及透明边缘。尺寸符合不等于风格符合，提示词符合不等于实际结果通过。
