# 可选彩蛋

仅故事适合或用户需要时添加。使用原作呼应或标记原创，写发现条件、互动反馈和可选奖励。
复用统一状态与交互，检查剧透、触发窗口、重复领取和资源消耗。删除全部彩蛋后主线仍应成立；不能拿失败结局可达冒充主线可达。
彩蛋不承担主线必需信息，不计入必经时长。不适合就不生成，无需为调用技能填数量。实际验证发现与跳过路径，未运行的结果明确标注。

在 Create World 工作台内使用时，先按需读取 [项目接入约定](references/workbench-v2.md)。技能可在完整任务中重复调用，不规定固定流水线。旧格式参考仅用于对应旧项目，不能覆盖当前合同。
