# 故事改编定位

从原作事件中选择本作必须呈现的目标、阻碍、行动与后果。保留已确认的角色动机、关键因果与结局，明确省略和原创的内容。
确定玩家身份、游戏范围、哪些过程适合操作、哪些适合简短呈现。以当前用户规格为准；约10分钟和至少5个有效场景不意味着堆字、空房间或强制往返。
每部作品都允许重新设计核心玩法。已有清晰方向直接推进；只有实质性分歧才比较方案。把详细规则交给 gameplay-design，不重复创作全部机制与对白。
把决定写入项目现有 design.json 的 adaptation，或等效权威文档。引用相关来源ID，保持已有ID稳定。无需独立长报告或旧bundle校验器。

在已有原作阅读和表现方式选择中执行[素材与内容边界](../visual-asset-production/references/content-boundaries.md)。正常冲突、武打、轻微伤势和恋爱直接保留；来源包含敏感情节不等于必须详细展示。仅涉及边界的片段在已有设计中明确表达尺度，不新增安全报告或审批。调整若改变关键因果、结局或明确玩法，提出具体冲突由上游/用户决定，不静默删改。

在 Create World 工作台内使用时，先按需读取 [项目接入约定](references/workbench-v2.md)。技能可在完整任务中重复调用，不规定固定流水线。旧格式参考仅用于对应旧项目，不能覆盖当前合同。
