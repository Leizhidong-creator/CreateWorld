# 可选分支与汇合

有真实选择需求才调用；没有分支是有效结果。取消默认侧路、回访、延迟奖励数量要求。
先确定玩家当时知道什么、选项产生什么不同后果，再写按钮文字。后果可影响信息、权限、资源、关系或路线；无需强行增加结局。
复用全局状态，明确汇合后保留的事实、互斥内容的反馈和可错过窗口。主线必需信息不能只放在可永久错过的支线。
修改相关节点与测试，不维护另一套完整bundle。实际检查各选项、汇合和原结局可达；测试超限写未覆盖，不删失败选项换通过。

在 Create World 工作台内使用时，先按需读取 [项目接入约定](references/workbench-v2.md)。技能可在完整任务中重复调用，不规定固定流水线。旧格式参考仅用于对应旧项目，不能覆盖当前合同。
