# 《高墙之外》玩家体验复刻提示词包

版本：2026-10-30 · 主线与第一结局版。本文是交给生成 Agent 的入口，可直接作为总提示词使用。

本包已纳入全部已确认决定，无遗留待确认项。进入第一结局时停止主游戏背景音乐和水管雨声，只保留结局声音；具体规则见[声音篇](11_声音与叙事节奏.md#a08-第一结局音乐与驾驶音)。文档核验范围及尚未完成的游戏实测见[来源说明](14_来源核验与范围变更.md)。

## 你的任务

根据本包的全部体验描述，生成《高墙之外》的可游玩版本。玩家从客厅观影进入黑墙庄园，完成取得石锤、取得圣经、藏锤通过搜房、海报遮掩、挖掘与撒土、二十年长期计划、绘制排水路线、调换账本、雨夜逃出，随后进入第一结局《相逢的海滩》，体验瑞德寻找橡树、取得信件、驾驶赴约与海边重逢。

你另外获得的源码只包括用户提供的摇杆、交互按键、地图、彩蛋等共通能力。它不等于本作的完整剧情实现。所有本作故事、任务和玩法关系均以本包说明为输入；不要把关键内容留待读取原游戏代码才能理解。

## 已确认的范围

- 保留取得圣经并藏好石锤的主线，以及该主线中的失败、重试、重复互动。
- 不制作石锤没收、当众惩罚、禁闭、领导来访、取回石锤的备用路线。
- 成功逃出后固定进入第一结局。不存在证据分数、收集阈值或条件选择其他结局的机制。
- 保留可选证据、NPC 闲聊、旁听和提前进入办公室的随机查房，作为探索内容；它们不改变主线路线和最终结局。
- 保留两种海报的外观选择，效果相同。
- 保留第一结局结束后的随机脱困风格卡。它不是基于行为的性格测评或评分结果。
- 不提供隐藏开发面板、剧情跳转面板及其他开发操作给玩家。

## 生成时必须遵守

1. **含义完整，语言重写。** 文档给的是信息和表达要求，不是可复制的成稿对白。对白、旁白、任务文字、失败提醒均需重新写作。人物名、物件名、地点名与关键证据数字可以保留。不得因为改写而删掉线索或改变人物动机。
2. **按阶段控制玩家知识。** 全局说明面向生成者，可以揭示故事全貌；玩家只能在相应事件发生后获知信息。不能一开始就解释后门转送内幕、隐藏账本的位置或橡树下的铁盒。
3. **尊重已提供的共通能力。** 组件的既有位置与交互约束按用户提供的源码执行。本包不要求重新布局摇杆、交互键和对话框，也不预设用户未提供的其他系统已经存在。
4. **外观可以设计，语义关系不能丢。** 自行安排构图、颜色、尺寸和路线形状，但要保证角色、门、关键物件可识别可到达；墙与障碍不能穿越；提示、实际动作及反馈彼此对应。地图中的连通、隔离、前置条件按文档保留。
5. **规则固定，调节参数开放。** 速度、时间窗口、重复挑战次数等可调整，但提示要同步，挑战必须可完成。二十年、证据编号和对应日期等属于剧情事实，不随难度调整。
6. **独立小游戏有清晰边界。** 修理收音机和整理图书是嵌入主游戏的独立体验；进入时暂停主场景操作，小游戏内部处理自身输入、反馈与重试。它们通过剧情入口、成功结果和界面风格与主游戏关联。不得把小游戏的每次操作变成主场景角色移动。
7. **探索不改结局。** 收集多少线索都不会切换结局；取得圣经、完成地图等主线条件仍然有效。不能把“没有结局分支”误解成跳过主线前置任务。
8. **不擅自补充故事。** 不添加隐藏评分、可选结局、战斗、购买系统、人格判定或调查破案结局。材料之间若出现无法消解的冲突，列出具体条目并向用户提问。

## 建议工作方式

先列出全部体验编号的实现对应表，确认唯一主线与可选探索之间的关系。完成后按主线顺序游玩到重逢，再分别验证小游戏失败、主线失败、可选探索和重播。每一项注明已实现、已运行验证或尚未验证；具体使用技术和工作阶段由你安排。

最终使用[自检提示词](13_自检提示词.md)复核。输出应能证明玩家体验已连通，不能仅以“页面能打开”或“所有文件都存在”宣布完成。

# 游戏总览与人物

返回[总入口](00_总入口与生成提示词.md)。流程见[完整体验流程](02_完整体验流程.md)。

## W01 故事与体验主轴

玩家开始是客厅中的观影者，被异常电视画面和白光带入电影世界，随后以安迪的身份行动。银行家安迪因陷害失去自由，被拘禁在黑墙庄园。开场试图直接从大门离开会遭遇黑暗和短暂手术室片段，醒来后认识到这处拘禁地的危险，也形成逃离和揭露它的愿望。

主线由小而具体的互助与行动组成：替瑞德修理收音机换得石锤，帮助老布整理图书获得私人圣经，用书掩藏石锤避过搜查，用海报遮住秘密通道，再学习如何把挖出的泥土带到院子处理。一次实际挖掘和撒土之后，通过二十年的蒙太奇表现重复劳动与长期坚持。

二十年后，安迪向瑞德确认路线线索，回房通过水管迷宫形成排水图纸。他利用长期协助幕后主使处理账务的身份接近办公室，揭开刺绣后的保险柜，用圣经替换罪证账本。随后穿过最终土洞，在雷声掩护下凿开水管，沿正确方向爬向出口。

本版本的故事固定以第一结局收束：瑞德循着安迪的指引找到橡树和信件，带着希望出发，穿越边境，最终在墨西哥海边与安迪重逢。可选证据让拘禁生活更有深度，但不另行展开审判或其他结局。

## W02 人物及表达基调

| 人物 | 玩家必须能理解的身份与关系 | 表达要求 |
|---|---|---|
| 安迪 | 被陷害的银行家；克制、观察、长期筹划；主场景的受控角色 | 面对权力保持谨慎，独白可以显露恐惧、疲惫和决心；不能直接向看守暴露逃离计划。 |
| 瑞德 | 能获得外界物件的同伴；先讲交易与风险，后建立互信；第一结局成为受控角色 | 初识时试探、警惕，合作后务实；海边篇的心理重心由不确定转向希望和自由。 |
| 老布／布鲁克斯 | 管理图书馆的年长同伴；珍惜书籍，守规矩，但愿意帮助踏实的人 | 先审视安迪的请求，再解释私人经书的珍贵，以劳动交换赠书，最终温和祝愿。 |
| 幕后主使 | 控制黑墙庄园并掌握账目的人；能命令看守搜查；相信安迪会继续为他处理账务 | 搜房时以规矩、虔诚和道德包装权力；办公室阶段显示自负与疏于防备。 |
| 看守 | 巡查院子、参与搜房、可能进入办公室的人 | 主线体现监视压力；可选谈话透露夜间转送异常，但并不因聊天就成为安迪的盟友。 |
| 汤米、海伍德、弗洛伊德 | 各自掌握部分见闻的同伴 | 日常闲聊表现生活；秘密交谈谨慎、压低声量，强调自身亲见或拾获的范围。具体内容见 E 系列。 |

“黑墙庄园”“幕后主使”是本版本采用的称呼；不要自行替换为另一版影视剧情中的机构、职务或人物设定。

## W03 道具的剧情职责

| 物件 | 获得与用途 | 必须保留的后续变化 |
|---|---|---|
| 石锤 | 完成收音机小游戏后获得；藏入圣经；挖掘、砸管 | 藏好不等于丢失；后期仍能用于通道工作。 |
| 圣经 | 完成书架小游戏并结束赠书对白后获得；先藏锤，后调换账本 | 调包后不再持有私人圣经，也不得重新触发早期藏锤任务。 |
| 海报 | 搜房通过后由瑞德交付；两种外观可选 | 选定后用于遮蔽房间墙面和洞口；选择不改变条件、难度或结局。 |
| 小土堆 | 第一次挖掘完成后获得 | 未处理前不能继续推进长期挖掘；撒土全部完成后从携带状态消失。 |
| 排水地图 | 二十年后向瑞德问路，再完成水管迷宫、收起图纸 | 是办公室主任务与最终逃离准备的一环；不是庭院探索小地图。 |
| 账本 | 在办公室揭开刺绣并以圣经调包获得 | 保留罪证到手的意义，解锁最终通道；不承担本版本的结局评分。 |
| 登记页、转送铜牌 | 可选探索获得的两件可携带物证 | 可打开查看原件内容；取得与否不影响主线结束。 |
| 黑曜石、铁盒、信件 | 第一结局橡树调查中的连续发现 | 它们引出安迪的邀约、瑞德出发和重逢；不是新增庄园装备。 |

## W04 空间逻辑

- 客厅是进入故事前的独立场景；白光后到达庄园大门附近。手术室只作为短暂叙事片段，不添加探索或治疗玩法。
- 庄园院子是活动枢纽：连接办公室、图书馆、房间走廊与劳作区。瑞德和其他同伴会在院内活动，看守会巡逻。
- 房间与院子之间经过走廊。走廊中其他锁门可以提供无法打开的简短反馈，但不能导入被排除的禁闭路线。
- 房间含可休息的床、可进行藏锤和画图的桌子，以及用海报遮掩的墙面通道。这些物件的作用随剧情阶段变化。
- 图书馆要能容纳进门、接近老布、交谈和离开。未获得相应邀请时进入，不得凭空取得圣经。二十年后不再把早期图书馆赠书任务作为可用任务。
- 办公室包含人物交谈区域、刺绣遮盖的保险柜、躲藏用窗帘和返回院子的门。主任务模式与提前进入的探索模式不能同时触发。
- 秘密洞口连接初次挖掘土洞；二十年后满足条件再通向最终土洞与水管。水管的一端是出口，反方向是坠落／溺水危险。
- 第一结局的橡树田野与道路是独立地点，不与庄园地图连成可自由往返的世界。石墙、树干与道路障碍具有实际阻挡关系，路线可以重新排布，但目标始终可达。

不根据以上关系规定像素坐标或画面朝向；任务中的方位提示必须与实际生成的布局一致。

===== 03_开场与初入庄园.md =====
# 开场与初入庄园

返回[总入口](00_总入口与生成提示词.md) · 后续[交易藏锤与海报](04_交易藏锤与海报.md)。本篇编号 P01—P08。

## P01 开始、继续与重新开始

**发生前**：玩家进入游戏，尚未进行本次操作。

**体验**：呈现《高墙之外》的标题与探索入口，开场画面传达高墙、雨夜和渴望自由的主题。持续雨声属于场景氛围；确认进入时有一次雷声强化转场。存在有效未完成进度时，提供继续与重新开始的区分。

**行动与反馈**：点击入口或使用确认输入。继续应恢复相应阶段；重新开始会清空本轮剧情进度和已探索庭院地图。连续输入不能重复开局或跳过多个未展示环节。

**文字要求**：让玩家明确这是开始新旅程、继续现有旅程还是放弃当前进度重来，不写任何结局条件或评分暗示。

**后续**：新游戏进入 P02；继续进入存档对应主线节点。已完成结局后重新进入主游戏，按新一轮处理，不自动回到旧结局选择状态。

## P02 客厅观影

**前置**：确认开始新旅程。

**体验**：短暂确认停顿与暗场后，玩家在客厅沙发上观看电视。电视画面交替、异常闪烁，日常环境开始不稳定。此时不是可自由探索的房间，不添加找遥控器等任务。

**行动**：通过点击画面或确认键继续观影。

**文字要求**：提示关注电视中的故事，并让玩家理解可以推进，不提前解释穿越的机制。

**后续**：进入 P03；开场菜单的雨声不应一直当作客厅移动音效播放。

## P03 故事前情与卷入

按以下信息顺序组织前情，采用重新写作的叙述：

1. 银行家安迪因陷害被带入黑墙庄园，失去行动自由。高墙、锁门、巡查和看守脚步逐渐侵蚀人的习惯、身份与希望。
2. 安迪没有接受在此度过余生。他将结识能获得物件的瑞德，也会从老布处取得圣经；石锤、泥土与账本将成为漫长计划的一部分。
3. 在故事画面与简短概括之间留出停顿，再让电视中的光把玩家卷入其中。

前情可以预告关键道具的意义，但不提前交代每个谜题答案、物件藏在哪里或如何完成调包。

**推进**：前情文字、故事画面、概括性叙述和后续暗场依次出现；可继续的阶段提供输入提示，短暂演出阶段允许自动完成。不能用一次点击把全部前情直接跳掉。

## P04 白光与首次到达

**体验**：黑暗过渡后，连续画面表现玩家被电视吸入，最终白光吞没画面。随后在庄园大门附近醒来，周围带有陌生和视野受限感。

**人物认知**：此时安迪首先感到迷惑并急于离开，尚未获得任何工具、伙伴关系或完整逃离计划。

**行动**：玩家能试着移动并靠近大门；引导重点是观察门与尝试离开，不在此开放全部交易与地图教学。

**后续**：在门前进行离开交互，进入 P05。不能直接把这次过门判作通关。

## P05 大门后的黑暗与手术室

**体验顺序**：离开尝试→黑屏中的质疑性文字→短暂手术室画面→另一段痛苦、恐惧的手术室画面与突发恐怖音效→再次黑暗。

两张手术室画面必须让玩家看出安迪躺在台上、手腕受束缚、周围有医疗器具和操作托盘，表情由不安转为更强的惊恐；他并非自愿接受普通治疗。具体构图和配色可设计，不凭图中暗示补写已经发生的具体器官摘除或医生身份。

**文字要求**：先质疑玩家是否真的摆脱了控制，再表达安迪对自己尝试离开却被送上手术台的困惑，暗示庄园隐藏着更可怕的用途。不要在这里直接揭示完整犯罪网络。

**交互**：大门后的第一段黑屏文字逐渐出现；第一次继续可以补全尚未显示的文字，完整显示后再次继续才进入手术室。两张手术室画面自动依次短暂展示，不可自由移动。最后的黑屏独白按阅读时长自动结束，再进入房间醒来，不要求额外选择才能脱离手术室。

## P06 房间醒来与行动目标

**体验**：安迪在房间床上恢复意识，内心逐渐将自己与电影中的安迪联系起来，表达逃出控制并揭露庄园的愿望；随后把愿望落实为先去寻找瑞德。

**对白要求**：区分惊恐后的自我确认、长期目标和眼下行动。不要让玩家在此知道石锤交易的完整要求，也不要把可选调查写成完成第一结局的前置。

**后续**：独白结束后进行 P07，再让玩家自己离床、走向房门。

## P07 首次操作教学

1. 单独介绍移动方式：拖动已有摇杆或使用 WASD。突出当前解释的控制，但不重新规定其位置。
2. 玩家确认后，再单独介绍交互：靠近可交互的人物、物品或门，使用已有交互键或空格，进行对话、查看、开门；对话期间也可用确认输入推进。
3. 教学期间停止世界推进，避免人物在阅读教学时被移动或剧情自行结束。
4. 同一次确认不得同时跳过两步。完成后本轮不再反复弹出，继续游戏也应记住已完成的教学。

## P08 房门、走廊、院子与地图初见

**行动链**：离床→靠近房门并交互→进入走廊→沿通道到院门→进入院子。走廊不是自动传送的过场，玩家需要实际行走；墙和非通路位置不可穿越。

**其他门**：靠近普通状态下的锁门，最多得到门从外侧锁住、内部无回应的简短反馈。该门不开放惩罚或禁闭路线。

**地图教学**：第一次从醒来的房间经走廊来到院子，才解锁庭院导航地图。提示走过的区域会逐渐显现，当前主线目标有标记。要求玩家实际打开地图完成这一步；打开时暂停场景，关闭后继续。

**玩家任务**：在院子寻找瑞德。地图的目标应跟随他的实际位置，不把一个移动人物永远标在固定旧位置。此时进入 M01；可选探索见 E 系列，但不能覆盖当前主线任务。

===== 04_交易藏锤与海报.md =====
# 交易、藏锤与海报

返回[总入口](00_总入口与生成提示词.md) · 前接[P08](03_开场与初入庄园.md#p08-房门走廊院子与地图初见) · 后接[挖掘与二十年](05_挖掘撒土与二十年.md)。本篇 M01—M10。每段对白均要求另写成自然对话，不直接把下列说明当台词显示。

## M01 初次向瑞德提出交易

**前置与行动**：完成初次醒来，在院子找到瑞德并靠近交互。双方停止走动，进入对话；顺序推进，没有改变主线的回答选项。

**逐段表达**：

1. 瑞德用入庄园第一晚的往事试探安迪：他曾认为这个新来者会崩溃哭泣，结果安迪一声不吭，害他输掉两包香烟。既表现院内残酷的消遣，也承认安迪超出预期。
2. 瑞德问来意，是普通交往还是有所求。安迪说明听说他能弄到外界物品。
3. 瑞德承认渠道，但强调风险与交换代价，不能表现成随便领取物品的商店。
4. 安迪请求一把小石锤，解释用来打磨小石头、保持安静的兴趣。瑞德怀疑金属工具可能用来伤人；安迪否认打架意图。
5. 瑞德给出具体交换：先修好他的收音机，再交付石锤。让玩家清楚下一步是修理，而不是搜钱、购买或偷窃。

**此刻的知识**：玩家知道工具需求和互惠条件；瑞德尚未公开协助挖掘脱逃。不要让安迪当面讲出完整越狱路线。

## M02 修理收音机的入口

对话结束后进入[G01](07_独立小游戏体验.md#g01-收音机修理内外轨道校准)。主场景停止响应移动和交谈，玩家按小游戏的两轨校准规则操作。尚未成功时不能领取石锤；重置只影响小游戏。成功后收回独立界面，进入 M03。

## M03 修理成功与石锤交付

**表现顺序**：收音机恢复，先有微弱电流／恢复工作的听觉反馈；瑞德认可安迪的手艺与可靠，兑现承诺；石锤成为已拥有物件。

**对白语义**：瑞德确认修理结果，安迪回应这项交换；瑞德提示自己已向图书馆的老布打过招呼，安迪可以去找他。语气从试探转为较信任，但仍处于戒备环境。

**反馈与去向**：获得提示、道具显示、下一目标指向图书馆。重复与瑞德交互不能反复修理或获得多把锤；此后可出现[E01](08_可选探索与证据.md#e01-探索开放时机与主线优先级)所述的探索对话。

## M04 老布邀请与私人圣经的交换条件

**进入方式**：取得石锤后，先在院子图书馆附近与老布交谈。他确认瑞德的介绍，随后走进图书馆。玩家等待他进门，再自行靠近入口并进入。提前进馆可能看到空馆或未就位状态，只引导回到相应人物，不发放圣经。

**馆内逐段表达**：

1. 老布识别新面孔并提起瑞德。安迪表示喜欢书，希望来看看。
2. 老布说明这里有规矩、自己看重书，追问安迪真正的来意。
3. 安迪请求一本可以自己保留、夜间阅读的圣经，希望借此稳定心神。
4. 老布说明那是珍惜的私人经书，不能把请求当成普通借阅。安迪表达在此生活需要一点精神依托。
5. 老布提出帮忙整理图书作为交换。安迪答应；老布看重他是否愿意安静、耐心地做事。

**认知控制**：这场对话的公开动机是阅读与安慰，不提前让老布讲出圣经藏锤方法或未来调包账本的安排。

## M05 整理图书与赠书

馆内交换对白结束，进入[G02](07_独立小游戏体验.md#g02-图书整理有限交换次数的高度排序)。任务文字必须表达选择两本交换、按高度排序和有限机会。

小游戏失败可重试，老布不惩罚安迪、不改成其他路线。成功后接回一段劳动结束的对话：先表现时间过去、书架变整齐；老布感谢认真整理，决定把自己的圣经赠给安迪，明确无需归还；以经书能在黑暗中给予安慰的愿望收束，安迪郑重感谢。

**授予时机**：完整结束赠书对白才获得圣经，更新携带物与任务，提示回房。重复到访不重做交换、不重复赠书。二十年前老布仍可承担可选线索对话，详见 E05。

## M06 在房间桌前藏锤

**前置**：同时持有石锤与圣经，回到房间；准备迎接搜房。任务明确先在桌前藏好工具。仅有石锤时应让玩家继续寻找圣经，不进入被排除的没收路线。

**交互过程**：靠近桌子并交互，进入局部藏物操作。玩家看见石锤与可容纳它的圣经内部空间，将锤拖入对应位置后松开。键盘可先确认拾起，以移动输入调整，再确认放下。无需限制书和锤的具体美术比例，但成功区域与放置反馈必须可读。

**反馈**：放错位置只退回可再次尝试的状态，提示尚未藏妥；没有次数上限、生命损失或另一剧情。放到正确位置后，锤被书掩藏，给出安心但仍须谨慎的内心反馈。石锤仍然属于安迪，不能从后续可用工具中消失。

**后续**：结束局部操作，保存藏好结果，目标转为床边等待检查。此阶段墙面如有查看提示，只用于暗示后续通道；不得要求玩家先完成挖掘才能避过搜查，也不要新增一个无提示的墙面检查硬条件。

## M07 床边接受搜房并通过

**触发**：藏锤成功后靠近床边交互。看守与幕后主使进门、接近床边、检查，再离开；演出和对话期间限制自由走动。

**逐段表达**：幕后主使命令安迪按规矩站好，宣布检查违禁物；看守报告只发现经书，没有发现工具；幕后主使借信仰、服从和秩序训诫安迪，把自我标榜的道德和控制欲并置。

**玩家理解**：藏锤已奏效，对方的虔诚姿态与压迫行为令人不安。此时并未找到犯罪账本，不能展示后续证据全貌。

**完成条件**：不仅播完最后一句，还要等二人离开。通过结果保留，重复靠近床不重新搜房。安迪的下一段思考转向找东西遮住墙上的痕迹，引导再找瑞德。

## M08 向瑞德索取海报并选择

**前置**：搜房通过，尚未取得海报。再次在院子找瑞德。

**逐段表达**：安迪低声找瑞德再帮一次忙；瑞德先询问石锤是否顺手，再强调暂时不愿冒险弄更多金属工具。安迪只请求大海报，不公开说出洞口用途；瑞德提醒海报体积大、搜房时容易看见，询问要哪种。玩家已知遮墙的真正目的，对方的对白不能把这个秘密直接揭破。选定后的长夜慰藉与调侃放在 M09。

**选择**：保留女明星海报与另一种海报这两个外观选项。前者表现女性明星，后者是带玩笑意味的非人角色形象；无需复制原人物相貌、角色形态或姿势。两个选项的名称与文案应能区分外观，不能标成道德、能力或结局倾向。选择只决定后续展示哪一种，不改变价格、任务、挖掘、证据或结局。

## M09 海报交付与返回

**表达**：瑞德调侃安迪仍有生活趣味，低调递交卷起的海报，提醒别在院子当众展开，回房再处理；安迪认可这份帮助。

**反馈**：展示海报由交付到成为携带物的可见过程，完成后解除对话，目标转为回房张贴。防止一次连续输入同时选定、领取、贴上，跳过交付。

**重复**：海报只有一份，选择后不反复弹出选择。可选闲聊或证据对话可以在主线交付结束后出现。

## M10 张贴海报与秘密洞口

回房靠近相应墙面交互，把已选海报贴上。墙面出现所选物件，遮掩区域从此可以作为秘密入口使用。未拿到海报不能凭空张贴；未通过搜房不能跳进第一次挖掘。

再次在墙面交互时，先表现海报／遮掩物被移开、洞口显露，完成短过渡再进入土洞。此处不新增密码、破墙谜题或道具合成。后接[M11](05_挖掘撒土与二十年.md#m11-第一次进入土洞与挖掘)。

===== 05_挖掘撒土与二十年.md =====
# 挖掘、撒土与二十年

返回[总入口](00_总入口与生成提示词.md) · 前接[海报入口](04_交易藏锤与海报.md#m10-张贴海报与秘密洞口) · 后接[办公室与逃离](06_账本与雨夜逃离.md)。本篇 M11—M17。

## M11 第一次进入土洞与挖掘

**前置**：已藏锤通过搜房，海报已贴好，没有携带待处理泥土，尚未完成本轮撒土阶段。

**空间与行动**：土洞的一端返回房间，另一端是尚未挖开的工作面。玩家实际走到工作面后长按交互。显示挖掘动作与进度；松开取消本次未完成进度，重新长按可再试。离开工作面不能远距离继续挖掘。

**完成**：进度满后取得一小堆待处理泥土，携带状态改变。文字强调工具虽小，计划开始向前推进，但泥土必须先处理。此时不能继续无限生产泥土，也不立即完成整条隧道。

**后续**：转入 M12。挖掘所需持续时间可调，但提示与反馈要一致。

## M12 携土返回院子

从土洞原入口返回房间，再经房门与走廊去院子劳作区。提示玩家携带的土会暴露计划，应去指定土地分散处理。正常步行携土并不会只因靠近看守就立刻失败。

未撒完时，房间床与墙面不得推进二十年或再次产土；重复交互应提醒当前土尚未处理。院子里的撒土交互优先于附近人物闲聊，避免长按被对话抢占。

## M13 在巡查压力下分次撒土

**地点与目标**：院子中一块可识别的劳作土地是有效撒土区。必须走入区域，在其中持续长按交互，才能把土逐次处理掉；在其他地面按键不计进度。

**每次行动的顺序**：

1. 按住后开始撒土动作与当前进度，玩家知道还需完成多少次。
2. 持续到一定阶段，附近的一名看守注意到异常并靠近；其他看守仍按自身巡查行事。接近反馈应让玩家有时间判断是否中断。
3. 玩家可松开并移动避让。松开或离开土地会取消本次未完成进度，不能边跑边积累；看守不再维持本次调查追近。已成功完成的次数在普通中断后保留。
4. 如果能在被接触前完成一整次，增加已处理次数，再寻找下一次机会。
5. 看守碰到**正在撒土**的安迪才构成本挑战失败；不把整座院子变成见人即败的追逐场。

**失败与重试**：说明异常动作暴露而被发现，进入失败反馈。继续后回到初次挖掘已完成、刚携带泥土的土洞阶段：保留石锤、圣经、海报与搜房通过，泥土仍在，本轮已撒次数清零，看守恢复巡查。玩家自行返回院子再试，不能要求重做交易或重新挖出这堆土。

**全部完成**：携带泥土消失，撒土任务结束，提示回床休息。无须精确复制原作三次长按、每次五秒、第三秒引起注意的节奏；可调整次数、时长和巡查速度，但要保留分次完成、中断避让和失败回到携土状态的规则。

## M14 回房休息

全部土处理完后，玩家按原路回到房间，靠近床并交互。安迪开始休息，画面淡出，进入 M15。床不是随时跳过任务的捷径；在此之前只给当前准备尚未完成的反馈。

## M15 二十年的重复劳动

**叙事作用**：一次实际操作教会玩家这个计划怎样实施；接下来用时间跨越说明他把同样的方法坚持了二十年。不能要求玩家实际重复二十年，也不能把二十年缩成几天。

依次表现四个画面／片段，每段包含明确事件：

1. 把石锤藏在床下等不显眼之处，白日生活继续。
2. 夜间在海报后秘密开凿，隧道日积月累延伸。
3. 白天把土藏在裤腿等随身位置，带离房间。
4. 在院内活动与劳作中把土慢慢散开，让痕迹融入普通地面。

配合克制的时间叙述，让玩家理解反复、隐忍、风险与希望。画面按顺序自动展开，阅读节奏允许调整；不能在尚未展示四个事件时接受一次按键直接跳完。全部结束后由玩家确认，回到床上醒来。

**返回后的变化**：二十年已过去；早期交易、赠书、藏锤、第一次撒土不再重开。图书馆不再提供早年的老布任务，老布也不再继续在院子承担旧交互。不要把另一条已删除路线中的老布告别情节自动补进本主线。

## M16 二十年后再次找瑞德

**入口**：醒来的内心叙述先感叹长期挖掘与等待，意识到接近计划最后阶段，再指引去找瑞德。经走廊进入院子，主线对话优先于瑞德可选线索。

**逐段表达**：

1. 瑞德感叹二十年过去，安迪似乎还在等待遥远甚至不可能的未来。表现双方熟悉已久，不像首次交易。
2. 安迪说明未来需要主动打通道路，而非空等。
3. 交谈转向排水路径与地图；瑞德提醒这种东西在控制严密的庄园里很危险，价值甚至超出普通开门工具。
4. 安迪理解风险，打算让图纸外观只像普通纸张，决定当晚回房画下线路。不要移入备用路线中瑞德从维修档案记下转弯、逐个口授的对白；本主线只讨论画图的必要和风险。

**结果**：记住这次讨论，任务转到房间桌前；重谈不重复推动时间。即使之前没有收集瑞德的财务线索，也必须能继续此主线。

## M17 画出并收起排水地图

同时满足二十年已经过去、已完成 M16，回房接近桌子并交互，进入[G03](07_独立小游戏体验.md#g03-地下水管迷宫走出路线并形成图纸)。此时桌子用于画图，不再弹出早期藏锤操作。

完成迷宫后，先展示与成功走过路线对应的放大图纸。玩家点击图纸或使用确认输入将它收起，才完成地图获得反馈，任务指向幕后主使办公室。

未开始、超时或取消重置都不授予地图；已经收起后重复桌子交互不能重复小游戏或重发道具。排水地图的用途是逃离准备，和早期探索用的庭院地图有明确区别。

===== 06_账本与雨夜逃离.md =====
# 账本与雨夜逃离

返回[总入口](00_总入口与生成提示词.md) · 前接[M17](05_挖掘撒土与二十年.md#m17-画出并收起排水地图) · 后接[第一结局](09_第一结局与风格卡.md)。本篇 M18—M26。

## M18 以熟悉账务的身份进入办公室

**前置**：已取得排水地图，尚未调包账本。经院子进入办公室，触发主线模式；不与提前擅入的警告或随机查房混在一起。

**行动**：靠近幕后主使交互。对话说明安迪这些年为其管理书籍、账目或资料，已形成被利用的信任关系。

**表达顺序**：幕后主使以惯常命令口吻提及长期处理账务的工作；安迪谨慎说明来查看文件；对方允许继续做事，透露自己要离开休息。安迪不能当面说要偷走罪证；此刻玩家还没揭开保险柜。

## M19 等待幕后主使实际离开

对话结束后对方起身／移向出口并离场。任务要求等待，不在最后一句刚显示时就自动打开保险柜，也不播放另一套查房倒计时。

离开完成，安迪可以自由探索，目标转为检查室内刺绣。再次进入办公室时，应根据已经完成的阶段继续，不能无限重播初次允许工作的对白。

## M20 刺绣后的保险柜

**行动链**：接近刺绣→交互检查遮盖物→保险柜显露→进一步看见内部账本。

**叙事语义**：刺绣承载道德／信仰姿态，背后却藏着罪恶账目，形成权力自我包装与实际行为的反差。安迪认出账本的重要性，意识到可以把真正证据带走。

**边界**：不新增密码锁、破解数字或钥匙任务；主线不要求先收齐五人证词。此前可选探索即使已经获得财务线索，也不等于此前已经打开这只柜子。

## M21 用圣经调换账本

**操作**：账本清晰可辨时，点击账本或使用当前交互输入，完成将圣经放回、取走真实账本的调包。

**反馈**：玩家看见替换发生，得知关键罪证已在自己手里；道具状态由持有圣经转为持有账本，石锤仍可供最终逃离使用。不能把圣经既留柜中又继续作为未使用物品展示。

**意义**：让之前帮助老布获得的圣经与眼前幕后主使的伪善发生联系，但不用原作台词。调包结束即开放最终通道，不进行证据计分或另一结局判定。

## M22 带账本离开并回房

完成后玩家仍在办公室，自行走到门边交互离开，经院子和走廊回房。不能用自动传送省略这一段风险解除后的返回。

任务提示带着已经取得的账本准备离开庄园。重复看柜子不再获取第二本，返回办公室保持任务已完成；不让旧警告或随机查房阻止已完成的主线状态。

## M23 最终土洞

回房靠近海报遮掩的墙面，打开通道进入已长期挖好的土洞。沿通道前进，到尽头进入地下水管区域。

这次已经不是第一次挖土劳动，不重新发泥土、不要求再撒三次或重播二十年。空间必须区分返回房间的一端与通向水管的一端，具体朝向可设计。

## M24 借雷声凿开水管

**环境**：雨夜，封闭的水管阻挡出口。明确呈现闪电／雷声的周期性信号、砸击位置与逐步破裂的管壁；先让玩家理解声响需要被天气掩护。

**目标和行动**：走到砸击处，等待雷电有效窗口，在窗口内开始长按交互并持续到一次砸击完成。完成一次增加破坏进度；同一窗口不能靠连按无上限叠加。未完成时松开只取消当前一击；下一窗口可以重新尝试。

**重要反馈**：管壁由完整到裂纹增多再到破口；当前长按进度、已完成次数与雷电窗口可辨。雷声承担时机提示，同时必须有可见信号，不能只依赖听觉。

**失败**：没有雷电掩护时新按下交互发起砸击，进入噪声暴露、被发现的失败反馈。若在有效窗口开始但未及时蓄满，窗口结束只清除该次未完成进度，不自动判败；必须松开，等待下一次信号再按下。文字说明失败原因与下次应等待的信号，不引入没收锤子的支线。

**重试**：玩家确认后回到房间海报前，保留地图、账本和此前主线进度，水管破坏进度重置。再次从最终土洞进入挑战。原作需要多次有效砸击，中途出现裂纹；次数、窗口长短与长按时间可调，必须保证至少存在可完成的操作机会。

## M25 进入破口并沿管道爬行

管壁打开后停止要求砸击，改为引导走进破口。玩家移动进入，经过下落／进入过渡，转为狭窄管道内的爬行。

**目标**：沿通向外界的方向前进直到出口。另一端通向坠落危险；走错并越过危险边界会落入水中而失败。不是复杂迷宫，不增加战斗、追兵、氧气或收集钥匙。

**失败后**：与 M24 相同，回房间海报前，保留主线物品，重置本轮管道进度。成功砸开的管子不应在失败重试后仍保持可跳过挑战的完成状态。

## M26 逃出与第一结局过渡

**成功链**：爬到正确出口→短暂黑暗→逃出生天的画面逐渐显现并出现成功主题文字→允许玩家继续→以不适合被困住的飞鸟隐喻自由，配合叙述声音与文字→留出最基本的听读时间→再次继续并淡出→未来与希望的过渡→进入 F01。

不要求使用原曲、原配音或原句，但保留挣脱压抑后短暂呼吸、回望与向未来出发的节奏。过渡前连续按键不能直接抹掉整段自由主题。

**唯一结果**：每次成功到达此处都进入《相逢的海滩》。财务口述、物证、旁听线索、收集数量、是否选女明星海报，一律不能更改结局。账本调包仍是主线行动，不因取消结局阈值而删除。

===== 07_独立小游戏体验.md =====
# 独立小游戏体验

返回[总入口](00_总入口与生成提示词.md)。本篇 G01—G03 是三个完整的小体验；主线入口见 M02、M05、M17。第一结局的橡树与驾驶在 F 系列中单独说明。

## 共同边界

修理收音机、整理图书各自独立于主游戏的走路与对话。玩家通过剧情进入独立操作区域，专注完成一种小游戏；主场景不应同时响应移动、重复交谈或重复交付道具。它们与主游戏的联系限于进入的剧情理由、结束后的剧情结果和一致的界面风格。

水管迷宫同样提供独立操作区域，其成功结果是路线图纸。三个小游戏都不能仅展示“任务完成”按钮替代实际玩法。小游戏内部失败与重置不等于主线重新开局；成功返回只发生一次。

不固定屏幕构图、色值、按钮位置或技术实现。下文中的目标特征、可操作对象与反馈必须清晰可辨。

## G01 收音机修理：内外轨道校准

### 剧情入口与返回

瑞德同意以修好收音机交换石锤。交易对白结束后，进入校准小游戏。全部目标完成后显示成功反馈，短暂停留，退出小游戏，接回收音机恢复和瑞德交付石锤的剧情。

### 玩家看到并理解的规则

- 一个校准球沿圆环自动绕行；有内、外两条可切换轨道。
- 两条轨道上分布需要收集的校准光点。光点属于特定轨道，不能在另一条轨道擦过时计为收集。
- 玩家控制的是切换轨道，不是角色走路，也不直接拖动光点或任意移动校准球。
- 显示已收集数量与总目标，已收集光点消失或有完成标记。

### 操作和反馈

1. 先展示玩法说明；点击开始区域或确认输入开始运行。
2. 运行中点击操作区域或确认输入，在内外轨道之间切换。切换要有可见位置变化与短促音效。
3. 球经过同轨道目标时自动收集，显示进度增加并给收集声音。已经收集的目标不重复计数。
4. 错过目标不会立即失败，也不清空已有进度；继续绕行，等待下一次机会。
5. 所有目标收集完毕才成功。成功状态停止继续累加，播放完成提示并返回交易剧情。

### 重置与音效

提供重新开始和小游戏音效开关。重置清空本局收集进度并回到待开始状态；允许新一局调整目标分布，但始终可完成。该玩法没有倒计时失败或生命扣除，不额外加入障碍碰撞惩罚。

### 调节范围

原作使用十个校准点。目标数量、转速和接触容差属于可调参数；必须保留自动绕行、两轨切换、同轨收集和全收集成功的关系。提示始终匹配实际目标数量。

## G02 图书整理：有限交换次数的高度排序

### 剧情入口与返回

安迪答应帮助老布整理杂乱图书，以此换取一本私人圣经。进入独立书架小游戏；完成后返回老布赠书的对白，结束该对白后取得圣经。

### 目标与初始情况

出现一排高度不同的书，排列被打乱。目标是让书按高度从高到低依次排列。初始排列必须确实能在给定交换上限内解决，不能随机打乱成不可能达成的局面。

书的高度差是判断规则的一部分，必须清晰可见；不要求复制原书名、颜色、封面符号和像素尺寸，也不设置阅读书内文字的额外谜题。

### 一次交换的完整过程

1. 点击一本书，明确显示已选择，并提示再选择另一本。
2. 再点同一本，取消选择，不消耗交换次数。
3. 点另一本，两本交换位置，只增加一次交换计数；清除选择状态。
4. 每次有效交换后检查全局高度顺序。已经排好则成功；未排好且机会用尽则失败；否则继续。
5. 提示区始终显示规则与剩余或已用机会，不能继续使用“反复点整理按钮”的旧任务描述。

### 失败、重试、成功

- 失败说明机会用完但排列尚未完成，提供重试。不能扣除主线中的石锤、圣经或其他已获得内容。
- 重试恢复本局原始排列，清空次数与选中项，让玩家可以依据刚才的观察重新规划。
- 成功显示完成状态和实际使用次数；不要求必须用满上限，提前排好也应成功。
- 成功后短暂停留，再关闭小游戏并返回赠书剧情。不能在失败或仅打开小游戏时就发放圣经。
- 提供本小游戏的重新开始和音效开关；选择、取消、交换与完成用不同的短声音反馈。

### 调节范围

原作是一排十本书、最多四次交换；所接入的固定局面最少需要四次。复刻可调数量和上限，但必须保留可解性、比较高度、选择两本交换、机会用尽失败和同局重试。它不是三次点按完成的劳动计数器。

## G03 地下水管迷宫：走出路线并形成图纸

### 剧情入口与返回

二十年后与瑞德谈过排水路线，回房间桌前进行画图。小游戏把路线确认表现为通过水管迷宫：成功后呈现实际走过的路线图纸，返回主场景显示放大的地图，再由玩家确认收起，获得主线道具。

### 可理解的规则

- 起点、当前所在位置、连通管道、墙壁和出口都要能辨识。
- 开始前提供说明；正式开始后倒计时。原作时限为二十五秒，复刻可调整。
- 按住并持续拖动，引导当前位置沿连通管道移动；方向键输入可以完成同样的逐步行进。不能点击远处就直接传送到出口。
- 管壁阻止移动；遇到死路允许回退，再选另一条路。移动过程记录路线。
- 出口是通向迷宫外的有效离开方向，不能只走到出口附近便误判通过。

### 反馈与失败

有效移动给简短移动反馈；被管壁挡住时给明确但不惩罚性的阻挡反馈。时间用尽进入超时状态，停止继续移动，提示重试。重试回到起点、清空路线、恢复时间，保持同一张迷宫，便于玩家学习。

### 主动重置与音效

进行中请求重置，应出现确认。确认期间冻结计时；取消则保留当前位置、已经走过的路线和剩余时间继续。确认重置后回到起点，重新计时。提供本小游戏音效开关，不把该开关键与主场景地图快捷键同时执行。

### 成功结果

完成后显示图纸已形成，并能看出实际走过的通路。返回主场景后仍有一次查看／收起地图的确认，随后提示去幕后主使办公室。不能把庭院导航地图当成这张排水图纸，也不能在倒计时失败后授予它。

### 调节范围

迷宫的具体形状、规模、时间与移动速度可以设计，但必须有解、可辨识、允许回退，保留“完成通路才能形成地图”的剧情条件。

# 可选探索与证据

## E01 探索开放时机与主线优先级

石锤交易完成后，人物可以提供额外谈话；圣经交付后还会再次要求刷新。原作会在玩家离开院子、进入房间／图书馆／办公室，再回院子时刷新可谈状态；不能刚领取道具就用同一次输入立刻强接秘密谈话。

瑞德先完成修理、石锤交付；他当前有海报交付、二十年后路线讨论等必做内容时，先处理必做内容。老布在院外先说进馆邀请，可以接着讲已开放的登记页线索，再走进馆；馆内如果线索已开放且未讲过，也可先完成该段，再继续赠书任务。可选谈话不得吞掉后续必做事件。对话时人物停下，结束后恢复原有活动。

每份直接线索只首次交付一次；重复交互可表达已告知、暂无新信息，不复制物证、不叠加计分、不反复完整演出领取过程。首次获得以简短记录反馈确认即可，**不能声称收集会提升某结局概率**。原作未提供完整侦探推理面板，本包不要求另加破案系统。

二十年后仍按人物是否在场决定能否交谈；老布离开当前活动范围后，不为补齐收集而凭空重现。可错过探索内容，但不可因此卡住主线。

## E02 瑞德的财务口述

**前置**：石锤已交付，探索谈话已开放，瑞德当前没有更高优先级的主线对话。

**逐段语义**：安迪询问不寻常的资金往来；瑞德说明自己替人跑过与账务有关的腿，见过付款名目。三个收款单位是**东港建材、哈德森修缮、格林运输**，账上在付钱，却没有对应实际施工或工作。付款日期为**六月十二日、七月三日、七月十九日**，这些夜晚后门都有卡车活动。瑞德不敢留纸张，担心搜查牵连自己。

**意图和情绪**：不是炫耀掌握大案，而是在信任下冒险分享有限见闻。让玩家理解资金与夜间运输可能有关，但不要把怀疑直接讲成已经判决的事实。

**反馈**：获得一份口述财务线索，不发放实体账本或发票。此线索与 M21 的真实账本不同，缺少它也能固定进入第一结局。

## E03 汤米的转送见闻

**语义顺序**：汤米回忆搬运过用于转送的牛皮纸档案；上面写着被拘禁者的编号，却没有接收机构的印章；他被告知要送往 **D 区**。其中三个人被带走后再也没有回来。

**表达要求**：安迪通过追问将“普通搬文件”推进到“去向不明的人”；汤米强调自己亲手搬过、亲眼见过的部分，对全貌仍不确定。保留谨慎和恐惧，不让他直接知道隐藏保险柜或边境邀约。

**结果**：记录目击口述，无实体档案进入背包。它与登记页、铜牌互相印证，不开启新的救人路线。

## E04 海伍德的灰色卡车

**语义顺序**：海伍德见过没有明确标志的灰色卡车；后部左侧车门有一块掉漆；车牌尾号 **417**。车辆分别在**六月十二日、七月三日、七月十九日**出现；夜间后门运输和随后人员消失让他不安。

**玩家理解**：外观特征用于辨认同一辆车，日期可与瑞德的账务口述对应。不要新增整张车牌、司机姓名、车内货物真相等原作未给出的答案。

**结果**：记录目击线索，不生成卡车实体道具，不要求玩家去驾驶或追踪这辆车。

## E05 老布藏在年鉴中的登记页

**前置**：石锤取得后的探索刷新完成，老布仍在当前时代可交谈。可在院外邀请之后、带路进馆之前获得；也可在馆内交互时获得，不要求先有圣经。赠书后若尚未获得，离馆回院刷新探索，再回馆找老布也可尝试这项交谈。二十年后不再提供补领。

**逐段语义**：老布谨慎地从《州立年鉴》的硬皮夹层取出裁下的原始登记页；说明三张借阅证被同一个人划掉，旁边留下转送记录，而人没有回来。他将折起的原页交给安迪，让安迪看具体编号、日期与馆藏章，强调这份留存原件比传闻更难被抹去。

**原页必须可读的信息**：

| 登记内容 | 对应值 |
|---|---|
| 原登记页码 | 47 |
| 第一人的编号与日期 | 17 · 六月十二日 |
| 第二人的编号与日期 | 22 · 七月三日 |
| 第三人的编号与日期 | 31 · 七月十九日 |
| 共同去向记录 | D 区转送 |
| 异常 | 缺少对应的归还／释放记录 |
| 原件识别 | 图书馆印章，与普通口述或抄写不同 |

原作的印章具有醒目标记作用，复刻无需固定红色或版式，但必须能看出这是带章原页。纸张折痕和旧记录感可以自由表现。

**反馈与后续**：登记页成为可点击放大查看的物证，关闭后回到当时场景。再次索取不复制第二张。主线不要求玩家做连线拼图或输入数字答案。

## E06 弗洛伊德拾到的转送铜牌

**逐段语义**：弗洛伊德在劳作土地区拾到一块铜牌，原本由麻绳系着，绳已经断裂。他认出夜间搬运的袋子上也有相似牌；车走后土被翻动、一些人的名字消失，使他怀疑这不是普通杂物。将牌交给安迪时应有怕被发现的谨慎。

**可查看原件**：正面编号 **D-17**；背面包含**后门**与时间 **02:10**；有穿绳处和断掉的麻绳。不得把它误成钥匙、门禁卡或必须输入的密码。

**玩家理解**：D 区和编号与其他记录形成联系，后门时间给出运输细节；线索仍属于调查见闻，不改变逃离路径。

**反馈**：铜牌进入可查看物证列表，重复获得无效。检视方式与登记页一致。

## E07 可查看物证与口述的区分

只有 E05 登记页与 E06 铜牌提供可打开的原件。点击相应道具后暂停现场活动，显示原件及其关键信息；以关闭、确认或退出输入返回，不推进主线对话、不让看守在阅读时完成抓捕。

瑞德、汤米、海伍德的线索是口述，不能凭空获得五件可查看原物。三类旁听也只是听到的事实。可以简短确认已记下，但不增加“证据已达若干份，开放另一结局”之类规则。

## E10 与普通院内看守交谈

探索谈话已开放时，靠近在劳作土地区内巡逻的看守交互，可得到围绕土地与夜间转送的警告或冷漠谈话：有些地方会在夜里转送前清理，名字和床位会消失，上级只关心编号对得上。语气体现压迫和对人的漠视。当前携土撒土交互优先，不用交谈打断长按挑战。

这不是招募盟友，也不授予进入后门权限。被删除的惩罚路线中“领导来访早晨的大门看守”专用对白不移植到这里。

## E11 提前进入办公室的首次警告

**条件**：尚未取得可启动账本主线的地图，却进入办公室；从未经历首次警告。

幕后主使发现安迪擅入，质问其来意，要求未经允许不要进入。完整读完警告后将玩家带回院子办公室外，主线进度和物品保留。记住已经警告，之后提前进入不反复播放同一初见事件。

不能在此取到账本、回收锤子或开启领导来访剧情。它表达区域受控，之后接 E12 的可选探索。

## E12 空办公室探索与随机查房

**条件**：已看过首次警告，仍未进入地图后的账本主任务。再次进入可能暂时空无一人。玩家可以走动查看、从门退出；每次进入有一定概率安排一次迟些发生的查房，不是每秒重新抽签，也不是每次必定查房。

**危险链**：门外脚步预警→明确短时躲藏倒计时→靠近窗帘并交互躲进去→看守或幕后主使进入巡查→在藏身处保持安静→来人离开→恢复自由探索和退出。

**操作要求**：单纯站在窗帘附近但未交互，不等于已经躲好；远距离按交互不能传送藏身。原作约五秒躲藏，出现查房的概率和延迟均可调，必须有可到达的安全机会。

**失败**：倒计时到而未藏好，表现被撞见。玩家确认后回到院子办公室外，保留主线和已得探索内容。失败不进入锤子没收路线。

**限制**：躲藏等待不能在关键时刻触发物证或日常对白抢输入；不要求每次来人都讲一整段额外阴谋。取得地图后优先 M18—M22，不叠加随机查房；调包完成后返回为完成态，不重新授予物件。

## E13 旧地点、边界与隐藏内容范围

院子建筑、锁门、尚不满足条件的入口应提供符合当前阶段的简短反馈：等待带路、先完成眼下准备、门锁着或目前没有新发现。不能让无效交互悄悄触发被删除路线，也不能每次失败操作都跳出长篇说明。

保留的隐藏内容为本篇秘密线索与旁听，以及[第一结局风格卡](09_第一结局与风格卡.md#f11-随机脱困风格卡)。不把开发跳转、改道具、测试面板包装成彩蛋。没有额外密码答案、隐藏首领或剧情结局需要生成者自行补造。

===== 09_第一结局与风格卡.md =====
# 第一结局《相逢的海滩》与风格卡

返回[总入口](00_总入口与生成提示词.md) · 前接[M26](06_账本与雨夜逃离.md#m26-逃出与第一结局过渡)。本篇 F01—F12。成功逃离后固定进入本篇，与可选证据多少无关。

## F01 第一幕：瑞德循约寻找

叙事视角从安迪转向瑞德。瑞德已离开高墙，循着安迪先前留给他的指引来到田野、石墙和橡树附近；他仍不确定等待自己的是什么，但决定赴这个约。

先呈现寻找的故事画面与简短叙述；玩家确认继续，进入 F02。第一幕只告诉他寻找地点，不提前把铁盒内容和重逢画面全揭开。

## F02 橡树小游戏：步行寻找

**目标**：操控瑞德找到石墙北端附近那棵足够古老的橡树。保留“石墙、北端、老橡树”的相互关系；可重新安排整个场地形状和视角，不固定屏幕坐标。

**行动**：使用移动输入在田野中行走，树干和石墙阻挡，必须绕行；不是点击树直接传送。靠近目标后出现调查机会，用交互继续。

**误认反馈**：其他树可被调查，但有对应解释：一棵太年轻，一处不符合石墙端点的位置，另一棵也没有目标所需的年代感。调查错误不扣分、不重开，瑞德继续走。离目标太远调查，给出尚未找到位置的短反馈。

**失败边界**：没有倒计时、生命值或战斗；不能因撞墙而死亡。该小游戏的难点是理解空间关系并走到正确树旁。

## F03 黑曜石、铁盒与信

接近正确老橡树后第一次调查，瑞德确认树的位置符合指引，并注意树根附近一块与环境不协调的黑曜石。玩家再调查一次，移开石块、露出隐藏铁盒。

用短暂近景／事件展示铁盒与信件被找到，再回到故事的下一幕。必须保留“先辨认树和石块，再揭盒”的两次发现层次，不能进入小游戏便自动发信，也不把铁盒做成需新增密码的宝箱。

## F04 第二幕：读到安迪的邀约

瑞德打开信件，得知安迪正在为新的生活做计划，需要一个值得信任的人帮忙，希望瑞德前来。信中传达希望能抵抗漫长困境、不应轻易放弃的信念。

**表达要求**：以安迪的书信语气写邀请，兼顾具体的“来帮我、来相见”和对未来的信心；瑞德的阅读反应从迟疑转为被打动。不要复制影视名句，也不要改成警方通知、财宝地图或调查委托。

玩家读完继续到 F05。找到信不直接跳到海边。

## F05 第三幕：乘车离开旧生活

呈现巴士驶离边境小镇的过程。瑞德带着安迪提供的路费／帮助出发，去往温暖而不会不断唤起旧痛的地方。

旁白把行动写成主动选择新的可能，同时保留离开熟悉限制的不确定感。不是被押送，也不是追赶安迪进行救援。确认后进入 F06。

## F06 第四幕：窗外后退的风景

瑞德在车中望着后退的树木与道路，意识到自己正越过曾经不得离开的限制／承诺，选择前往边境另一侧见安迪。保持他的紧张和希望并存。

本段不是道德选择菜单；玩家不选择留下或返回高墙。确认后进入 F07 的驾驶道路体验，用行动承接“正在出发”的叙事。

## F07 驾驶小游戏：沿道路驶向边境

**入口说明**：安迪留下的帮助足以让瑞德踏上旅程；玩家要操控车辆沿道路到达通向边境的出口。故事画面中的乘车叙事和小游戏的车辆操控共同表现这段旅途，不新增职业司机剧情。

**操作**：以移动方向／摇杆控制车辆。第一次确认或移动开始行驶；车辆具有加速、惯性和松开后减速的过程。前进和转向反馈清楚，不能把它做成点终点自动完成。

**空间规则**：道路、边界与阻挡物形成可通过的线路；撞上阻挡处会停下或失去对应速度，能够调整方向继续，不死亡、不扣生命。路线出口必须真实可达；具体道路形状、起终点坐标可设计。

**成功条件**：车辆实际进入出口范围后成功，停止引擎的持续音，给到达反馈，收回小游戏返回 F08。

**没有的规则**：不加竞速排行、倒计时、燃油、罚款、追捕、载客任务或碰撞次数失败。玩家可以慢慢辨路，速度与惯性只影响手感。

**声音**：引擎低音随行驶速度变化，停车减弱，抵达时有短促成功音。它与结局音乐共处，但不应遮掉必要叙述。

## F08 第五幕：瑞德抵达海滩

瑞德终于来到墨西哥海边，露出放松的笑容。旁白表达他正在恢复作为一个人的自我感，不再只是被拘禁时的编号 **30265**。

海、沙滩、开阔空间承担与高墙生活的对照；不固定海水颜色、镜头构图或角色比例。玩家推进到 F09。

## F09 第六幕：与安迪重逢

安迪已经在那里等待，瑞德与他相见。表达约定被兑现、长久信任得到回应，两个人获得重新生活的可能。温暖、克制，不需要添加审判现场、幕后主使结局或新的任务。

这幕完成第一结局的故事闭环；玩家读完后推进到 F10，而非立即返回庄园。

## F10 结局标题与风格卡过渡

六幕故事和两个嵌入小游戏全部经过后，显示《相逢的海滩》的完成状态。随后以短暂提示把玩家带到“本次脱困风格”展示，进入 F11。

不能跳过驾驶或寻树就当作已完成六幕，也不显示另外两个结局的入口、剪影或解锁条件。

## F11 随机脱困风格卡

完成结局后，从以下四种卡随机显示一种。原作随机抽取，**不依赖证据数量、操作速度、海报、失败次数或玩家性格**。卡片文案应作为故事结束后的趣味表达，不宣传为真实心理测评。

| 卡名 | 需要重写表达的核心含义 |
|---|---|
| 洞察者 | 留意别人忽略的小线索与瞬间，从观察中读出离开的可能。 |
| 突围者 | 面对突然的变化敢于行动，朝已经出现的出口继续迈进。 |
| 策局者 | 安静观察、把零散可能联系起来，愿意为远处的机会做准备。 |
| 潜行者 | 关注细节、缝隙与时机，在低调的行动里一点点获得空间。 |

美术与排版可重做；保留四种名称及各自意涵，不把卡名直接改成技能、数值奖励或分支存档。每次重播后重新抽取可以抽到同一张，不能承诺一定不重复。

## F12 重播本结局

完成界面提供重播入口，回到第一幕重新展示故事，橡树与驾驶也恢复各自初始状态。它重播的是第一结局，不要求玩家重做修收音机、藏锤和二十年主线。

若退出结局并重新进入整个主游戏，按[P01](03_开场与初入庄园.md#p01-开始继续与重新开始)的完成后新一轮规则处理。二者不能都标成同一个含义不清的“继续”。

===== 10_共通体验与任务提示.md =====
# 共通体验与任务提示

返回[总入口](00_总入口与生成提示词.md)。本篇 R01—R09 只定义跨场景规则；具体谜题正文不重复。配套源码负责摇杆、按键、对话框等组件的实现与既有位置。

## R01 移动与就近交互

自由行动时，摇杆或 WASD 控制当前角色移动。可辨认角色朝向、行走和停止；墙、家具、建筑边界及其他明确障碍限制通行。门需靠近再交互，不能点击远处入口直接穿越地图。

交互键／空格依据当前对象表达开门、交谈、查看、拾放、继续等含义。点按和长按区分：挖掘、撒土、砸管需要持续输入；普通对话不需要一直按住。放开输入后停止相应动作，切换场景时不带着旧的长按继续行动。

人物在可达处活动，交互距离合理；进行对话时双方停下，结束后恢复活动。若同一区域存在多个机会，当前主线关键操作优先，例如携土时的撒土不能被邻近看守闲聊抢走。

## R02 对话、旁白与获知信息

使用配套组件区分说话者、人物对话、安迪心理与非人物叙述。普通对白按一次确认推进一段；启动对话的同一次输入不能顺便跳过第一段。逐字显示的黑屏叙述先补全，再以另一次确认继续。

获得道具或线索先给清楚的获得反馈，再接心理叙述或更新目标，避免同时挤压而漏读。玩家阅读时不能继续误触门、海报选择或身后的小游戏。日常旁听按自身节奏轮换，但世界暂停时也暂停。

人物不能知道玩家尚未发现的可选线索；没有调查过的安迪仍可说自己要逃离、已取得主线账本，但不能突然逐项背出未听过的车牌与日期。

## R03 庭院导航地图

P08 时首次解锁，展示安迪位置、当前主线方向和未探索区域。随实际行走逐步揭露区域；接近地点后记住地标。地标包括大门、办公室、图书馆、房间入口与劳作区，连接关系与实际场景一致。

点击地图入口或按 M 展开；展开时停止庭院人物和巡查推进，显示完整探索范围与图例；点击关闭或再次按 M 收起并恢复。切离院子时收起。其他独立小游戏内的 M 是本小游戏音效开关，不能同时展开庭院地图。

地图跟随任务与人物位置：目标在已探索区域时标明位置，尚未探索到时仅提供方向，不因此强行揭开全图；不显示其他结局任务。继续游戏保留本轮已探索区域；重新开始清空。地图只负责导航，不替代 M17 的排水图纸，不提供瞬移或导航自动走路。

## R04 道具呈现与使用

获得道具后能看到当前携带状态，物证在其他物品较多时仍可被查看。主要变化如下，具体获得条件见[W03](01_游戏总览与人物.md#w03-道具的剧情职责)：

- 锤藏入圣经时，以经书包含工具的状态表达，不误示锤已永久遗失。
- 海报未张贴时为携带物；贴好后在墙上显示，物品栏不继续显示第二份未用海报。
- 泥土只在待处理阶段携带，全部撒完消失。
- 圣经调包后离开携带状态，账本出现；石锤仍可操作。
- 排水图完成且确认收起才成为已持有物件。
- 登记页与铜牌可点击查看；其他道具不强行增加无来源的检查、丢弃、出售、合成菜单。

道具在对应地点自动匹配合法用途，只有藏锤局部操作要求明确拖放。不额外要求先在物品栏手动装备，否则容易增加原作没有的障碍。

## R05 暂停、输入隔离与音效控制

主场景允许使用 Esc 暂停；暂停画面让玩家知道如何恢复，可用 Esc 或确认继续回原场景。地图、物证查看、操作教学属于各自覆盖层，按其关闭规则回到现场，不能在读图时继续被巡查追近。

独立小游戏接管自身操作，主场景不同时响应；结束后恢复当前剧情目标，成功奖励只发一次。暂停或覆盖层退出后不应残留按住移动、自动推进多句等状态。

原作没有独立的综合设置页；本包不要求添加画质、语言、键位重绑或音量滑块。G01—G03 内各自提供音效开关与重新开始，按其文档处理。标题里的开始／继续／重开与小游戏重置必须分清。

## R06 自动记录与继续游戏

采用阶段性自动记录。玩家关闭后回来从最近完成的阶段继续，不承诺恢复到每一帧位置、每一句对白或未完成长按。记录已取得的关键物品、海报选择与张贴情况、主线阶段、已完成教学与庭院探索；已经保存的可选线索不得重复发放。

| 最近完成的阶段 | 继续游戏应落在的体验位置 |
|---|---|
| 白光到达 | 初次院子大门体验，尚未完成那次离开尝试 |
| 房间醒来 | 房间床上及醒来引导；完成过的操作教学不必重弹 |
| 石锤交付 | 院子，继续找老布 |
| 圣经交付 | 房间，准备藏锤 |
| 藏锤成功 | 房间，准备床边搜房 |
| 搜房完成 | 房间，准备找瑞德要海报 |
| 海报已得 | 房间，依据是否已经张贴给出贴海报或进洞目标 |
| 第一次挖掘完成 | 携土的土洞，准备去撒土 |
| 全部撒土完成 | 房间床边，准备休息；若二十年已记录则去找瑞德 |
| 二十年后瑞德谈话完成 | 房间，准备桌前画图 |
| 地图收起 | 院子，准备去办公室 |
| 办公室主线谈话与离场完成 | 空办公室，准备检查刺绣 |
| 账本调包完成 | 房间海报前，准备最终逃离 |
| 进入砸管阶段 | 水管挑战开始位置，不续接一半长按 |

探索记录附属于当前主线进度，不形成“证据积分存档”。原作不是任意时刻逐帧保存；交付中不宣称未到后续保存点的每一句闲聊都已可靠持久化。若生成者改变自动记录的粒度，必须保证恢复后物品、阶段和提示相容，不跳过未做任务。

已完成逃离并进入结局后，再加载主游戏按新轮处理；结局内重播则只重播 F 系列。重新开始会放弃本轮主线与庭院探索，不能带着旧账本或全亮地图进入开场。

## R07 失败与重试

失败说明必须包含发生了什么、当前可如何继续；惩罚仅按[失败表](02_完整体验流程.md#失败与返回关系)执行。尤其不能把小游戏失败升级成全局重开，也不能把被发现送进已删除的禁闭支线。

普通中断、查错、撞墙与明确失败区分。出现失败后等待玩家确认，不在后台继续累计失败、移动或播放另一场对话。

## R08 任务文字的语义目录

下表定义每个阶段提示要让玩家理解的动作，不是原句。显示方式由共通源码负责。正文对话展开时可暂隐任务，读完后恢复当下正确目标。不得使用和新布局冲突的固定屏幕方位。

| 阶段 | 提示必须传达的信息 | 条件、反馈和下一步的唯一正文 |
|---|---|---|
| 菜单、电视、前情、白光 | 开始或继续，哪些阶段可按键，哪些需等转场 | P01—P04 |
| 初到院子 | 观察大门并靠近尝试 | P04 |
| 黑暗与手术室 | 意识混乱，阅读并继续，无自由探索目标 | P05 |
| 醒来与走廊 | 找瑞德；离开房间后沿可走通道去院子 | P06—P08 |
| 瑞德初交涉 | 完成约定的收音机修理 | M01—M03、G01 |
| 图书馆入口 | 先找到老布、等其进馆，再跟进去 | M04 |
| 图书馆内 | 帮助整理图书；选择两本交换，有限机会排高低 | M05、G02 |
| 圣经到手 | 回房桌前把锤藏好，再去床边 | M06 |
| 检查进行中 | 等待入室、推进对白、等离开 | M07 |
| 检查结束 | 寻找瑞德，取得并带回海报 | M08—M09 |
| 海报在手／已挂 | 先贴到目标墙面，再打开遮掩入口 | M10 |
| 土洞工作面 | 靠近工作面持续挖掘；完成后原路出去 | M11—M12 |
| 携土院子 | 在有效劳作土地区分次处理，注意靠近看守 | M13 |
| 撒土全部结束 | 回房到床边休息 | M14 |
| 蒙太奇与醒来 | 二十年重复劳动；结束后再找瑞德 | M15—M16 |
| 路线已讨论 | 回房桌前走通水管迷宫，画图后确认收起 | M17、G03 |
| 地图在手 | 进入办公室找幕后主使 | M18 |
| 办公室剧情 | 等离场、检查刺绣、找账本、圣经调包、自行离开 | M19—M22 |
| 最终通道 | 从海报进入，向通道尽头走 | M23 |
| 水管未开／已开 | 按雷电提示长按；开口后进入并向出口爬 | M24—M25 |
| 成功过渡 | 等待画面与语音到可继续阶段，再推进 | M26 |
| 办公室可选探索 | 初次听警告；后续脚步预警后及时藏身，等待离开 | E11—E12 |
| 结局 | 寻树、调查石块、读信、驾驶到出口、阅读重逢、重播 | F01—F12 |

任务不能提前透露尚不可知的正确树下藏物或保险柜内容；危险提示必须在玩家有机会行动前出现。结局固定不代表这些过程条件可以省略。

## R09 反复返回时的阶段一致性

回到房间、院子、图书馆和办公室时，以已经完成的事件决定可操作内容：早期桌前藏锤，后期画图；早期床触发搜房，中期触发长期休息；墙面先张贴再进初次土洞，最终进入完成的通道。旧入口不能重发任务奖励。

可自由探索并不等于任何时代所有交互都开放。二十年后图书馆旧任务关闭；已拿账本不重做调包；在院子无土时不显示长按撒土；完成主线后不重新计算结局。具体返回反馈尽量简短，保持当前任务可见。

===== 11_声音与叙事节奏.md =====
# 声音与叙事节奏

返回[总入口](00_总入口与生成提示词.md)。本篇 A01—A08 规定声音的玩家作用和时机，不指定原曲、配音演员、乐器编制或资源文件。核验边界见[来源说明](14_来源核验与范围变更.md)。

## A01 菜单、雨声与进入

菜单雨声持续循环，建立高墙雨夜的氛围；确认开始／继续时一次雷声强调跨入故事。声音能播放时就属于环境，不要每次点菜单都叠加一层新的雨声。

进入客厅后结束菜单天气氛围。浏览器等环境若需第一次操作才可出声，接受这一限制，不能因此阻断游戏。

## A02 主游戏背景音乐

主游戏有持续背景音乐，首次有效输入后开始循环，为压抑生活、隐忍筹划与前进提供情绪底色。它不承担密码或必须听清才能通过的独有信号。

本次未对原音轨进行人工听辨，故不指定原作乐器、曲式和调性。生成时可围绕相应阶段的叙事功能选用或创作音乐。不要因反复进房、打开物证或重试叠加相同音乐实例。主游戏切入结局时按 A08 停止前段声音。

## A03 移动脚步

房间、走廊、图书馆、办公室的行走对应较硬地面的脚步；院子对应土地上的脚步。实际移动时出现，停止移动时停止。原作脚步有不同地面分组，不要求固定采样音色。

土洞行走与砸管前地面行走可有脚步，正在挖掘／砸击不同时假装在走路。对话、地图展开、物证检视或暂停时不继续播放移动脚步。爬行可表现身体运动，但不把直立走路音不加区分地铺满整段。

## A04 开场不安与收音机恢复

手术室突发的恐怖声是一次性冲击，跟随对应短片段，不无限循环、不延续到房间教学。先前的安静和黑暗使其有作用，不用持续巨大声压代替叙事。

G01 成功返回时，收音机恢复的微弱电流／工作声与瑞德确认对应。无需安排原作没有的长篇广播任务；校准球每次切换和收集的声音见 A06。

## A05 巡查与雷电操作提示

办公室可选查房在人员进门前用脚步预警，配合可见的躲藏倒计时。藏好后等待来人走入、巡查并离开，声音随这一过程结束。

水管挑战持续雨声；每次有效雷电窗口开始时有雷声，与可见闪电提示同步。它告诉玩家什么时候可以发起砸击，是实际操作信号。窗口结束后提示恢复等待，不把背景音乐节拍错当雷声。

水管雨声在进入第一结局时按 A08 停止。声音和可见提示要保持同一时机；关闭音效的玩家仍可根据画面完成挑战。

## A06 三个独立小游戏的短音效

G01 使用短电子音区分切换轨道、收集、全部完成；G02 用短音区分选中、取消、交换和完成；G03 对有效移动、受阻和成功提供区别。原作以合成的短促电子音为主，持续时间短，不是需要辨别旋律的音游。

各自的音效开关只控制对应小游戏；重置后反馈与重置后的状态一致，成功离开时不残留循环或重复触发完成音。规则说明和失败理由仍必须可视化。

## A07 逃出后的自由主题

M26 先让成功画面出现，再进入与飞鸟自由隐喻相配的叙述声和文字。语气从紧张转向释然、回望和希望。重新写作内容，可以重新录制或生成声音；不要直接提供原片段原句。

第一次可继续输入要在基本听读时间之后，确保主题至少能被感知；无需强制保留原音频秒数。此后淡出并接第一结局，音频结束或切换时不在下一幕背后重复讲上一段。

## A08 第一结局音乐与驾驶音

**已确认的切换规则**：M26 完成并进入第一结局时，停止主游戏背景音乐与水管雨声，只保留当前结局的声音。即使结局音乐尚待首次推进才开始，主游戏音乐和雨声也不继续播放；在结局内推进、进入小游戏或重播，不得重新启动这两路前段声音。

第一结局从首次推进后播放自身循环音乐，服务于寻访、迟疑、出发与重逢，情绪可由克制逐渐舒展。橡树小游戏与分镜属于同一段旅程，不重新叠起第二份相同背景音乐。

驾驶时增加低沉引擎合成声，速度上升时音高／强度随之变化，停车减弱，完成退出时停止；抵达配短成功提示。风格卡是完成后的轻松余韵，不新增评分播报或警报。

原作各音乐资源的具体听感未经本次人工试听确认；以上情绪是复刻需要达成的叙事功能，不能当成原曲分析报告。

此切换规则由用户于 2026-10-30 确认，取代原作中前段声音与结局音乐叠放的行为；保留结局自身音乐和驾驶音的上述触发规则。

# 交给生成 Agent 的自检提示词

返回[总入口](00_总入口与生成提示词.md)。本篇可直接复制给生成 Agent；必须连同整套体验文档使用。本次交付的是核对要求，不代表重新生成的游戏已经跑过下列检查。

## 你的核对任务

请依据《高墙之外》体验提示词包，检查你生成的游戏是否完整实现“成功藏锤主线＋第一结局＋可选探索”。不要只检查文件、界面外观或功能名称。逐项定位玩家实际遇到的条件、可执行动作、反馈和后续去向。

先读 00 的范围约束与 14 的原作核验边界，再按 12 的内容编号建立对应表。每项分别标注“材料中有描述”“已实现”“实际运行验证”“未验证／存在问题”。只有真实运行过的项才能标注通过；截图、源码推导、调试跳转与正常路径运行分别注明。

遇到材料未定义的剧情、条件矛盾或无法判断的原作异常，列出相关编号、实际表现、证据、影响和需要用户决定的选项。不要偷偷增加分支或用你对影视原作的记忆填补本包。

## 必跑的主线验证

1. **从无存档开始**：完成客厅、前情、白光、大门尝试、手术室、醒来、教学和走廊，确认不是按开始便跳到交易。地图必须通过实际打开完成教学。
2. **收音机交易**：先看瑞德提出条件，真正完成两轨收集，再得到石锤。错过光点不死亡，重置只重置校准，成功奖励不重复。
3. **图书馆交换**：等老布带路，逐段表达私人经书与劳动交换；选两本交换排序。先用完机会失败，再同局重试成功。圣经在赠书对话结束后才到手，旧“整理若干次”提示不得出现。
4. **唯一藏锤路线**：没圣经时尝试回房不能触发没收支线；拿齐后放错一次，再正确藏锤。床边搜房完整进场、检查、离场，通过后只能转向海报主线。
5. **两种海报**：分别验证一次两种选择；交付、张贴与入洞均可用，效果与最终结果相同。不允许自动拿到两种或为某种加隐藏条件。
6. **挖掘与撒土**：先中断一次挖掘，再完成并携土走到土地。中断撒土保留已完成次数；主动让调查者碰到正在撒土的角色，验证回到携土土洞且次数清零。重试完成后土消失，回床才跨越时间。
7. **二十年与地图**：四段重复劳动完整呈现，不能提前一键跳光；醒来再找瑞德，完成路线谈话后桌子才开迷宫。超时不能得图；通关后查看并收起图纸才去办公室。
8. **办公室账本**：与主使对话、等其离开、揭开刺绣、发现账本、圣经调包全部发生。调包前后物品正确；玩家自己走出办公室回房。不得提前取证或调包后还保留未使用圣经。
9. **雷声与爬管**：无信号时发起砸击会失败；有效窗口内完成一次才计数；按晚而未蓄满不错误计分。破口形成后才能进入爬行。反向到危险边缘会坠水；两种失败都回海报前并重置水管进度。正确走到出口才进入胜利过渡。
10. **结局完整链**：经过自由主题过渡、瑞德寻树、发现黑曜石、揭盒、读信、出发、车窗叙述、驾驶抵达、海滩与安迪重逢，再出风格卡。没有跳过两个小游戏的自动通关。

## 探索和结局不相互设门槛

分别运行以下收集情况，成功逃出后一律是第一结局：不收可选线索；只收瑞德财务口述；只收物证；收齐五位人物直接线索；收齐直接线索和三组关键旁听。不得设置“没有瑞德情报就无法重逢”，也不得因收太多证据改去审判结局。

核对五组直接线索的具体事实：三家公司、三个对应日期、417、47 页、17／22／31、D 区、D-17、02:10。纸页与铜牌才是可查看原件；没有物件的谈话不要伪造成实体文件。主线先后优先级正确，老布线索不被错误锁到赠书之后。

逐一观察 E08a—E08j 的十组日常内容和 E09a—E09c 的三组关键旁听。远处发生但没听清不能算获得，近处听到关键回应才能记录，重复不累计。时间跨越后不能让不在场的人继续参与。

提前进入办公室先受警告，之后检查有查房和无查房的访问；查房时分别验证藏好等待和超时被发现。持有地图后进入主线，不叠加随机检查。失败不改变主线物品或转入禁闭路线。

## 重试、重访和继续游戏

- 按 02 的失败表逐行验证，不用一个统一“回开始菜单”代替不同返回点。
- 检查暂停、地图和物证打开期间世界确实停止；关闭后输入不残留，人物不突然冲出去或连续跳过多句。
- 在 R06 列出的主要阶段退出并继续，核对物品、任务、教学、庭院探索；只恢复已记录的阶段，不凭空补全未完成任务。
- 回旧地点检查桌子、床、海报、图书馆和办公室，不重复发锤、圣经、地图或账本。
- 结局重播应回第一幕并重置两个结局小游戏；整个主游戏重开要清空旧进度和探索地图。

## 文字、画面与声音

逐段检查说话者、场景、事实、意图、情绪和信息揭示是否齐全。语言必须新写，不能拿原台词大段粘贴交差。任务文字要指向当下可执行的动作，不提前透露未发现信息，不沿用错误玩法或失效方位。

画面不要求原构图或配色，但有意义的物件、阻挡、人物移动、物品交付、圣经藏锤、海报遮掩、裂纹、土消失、柜内调包和重逢必须可见。别用一段文字代替所有可玩行动。

检查雨声、脚步、雷电窗口、查房预警、小游戏短音、逃出主题叙述、结局音乐和引擎的开始／结束。关闭声音仍应能理解操作；不宣称没有听辨过的原曲特征。

进入第一结局时，单独确认主游戏背景音乐与水管雨声已停止，仅结局声音可播放；在结局音乐尚未启动时，也不能留下前段声音。继续推进、进入橡树／驾驶小游戏及重播结局，均不得使主游戏音乐或雨声恢复。这是用户确认的复刻规则，不沿用原作叠放行为。

风格卡应随机显示四种之一，不声称根据玩家行为准确判断人格。只检查它的展示与重播，不作为结局等级。

## 输出核对报告

报告包含：

1. 覆盖表：内容编号、生成游戏中的入口／表现、验证方式、结果。
2. 正常游玩路径：从新开始到第一结局的实际操作记录，并列出使用过调试辅助的地方。
3. 问题表：编号、预期、实际、证据、影响、是否需用户决策。
4. 未验证清单：明确哪些只是读代码或看到单帧，不能用“整体通过”掩盖。
5. 结论：区分内容已描述、已生成、已静态检查和已实机验证；只对实际证据支持的范围作完成声明。

本提示词要求检查玩家体验，不要求特定代码架构、前后端形式、框架、接口命名或组件坐标。
