# 本轮改造记录

本轮实现一次提交整部游戏、自主安排内部工作、按故事设计核心机制的制作方式。默认目标约10分钟、至少5个有效场景；这个规格是制作目标，不能用自动通关秒数冒充真人游玩时长。

## 保留、移除与替换

| 处理 | 内容 |
| --- | --- |
| 保留 | 项目管理、自然语言修改、版本回退、独立HTML5导出；通用移动/镜头/碰撞/对话/状态/存档；原生生图与真实浏览器测试。 |
| 从生产调度移除 | 固定六阶段、全部14技能必跑、预设任务百分比、每个阶段重复交报告。旧适配器留作历史兼容，不在新制作入口调用。 |
| 替换 | 六阶段执行器→持久Codex完整任务+按需宿主工具；固定机制→剧情规则+extensions实现；模型自报通过→对应当前候选的真实操作与独立审阅。 |
| 简化 | 艺术方向不默认做多候选盲测；对白不强制多稿评分；可选支线/彩蛋没有数量指标；权威数据集中，按需拆内容分片。 |
| 补齐 | 中途恢复、机制取消/失败/成功回传、特殊动作播放与事件、基础图集统一脚底、逐项素材恢复、过期证据失效。 |

## 14个技能

| 技能 | 当前职责与调整 |
| --- | --- |
| content-understanding | 因果、动机、结局及来源定位；明确缺口与原创补充，不代写玩法。 |
| game-adaptation | 玩家身份、取舍及本作范围；无需固定候选方案数量。 |
| art-direction | 固定像素规范，按题材调整配色服装建筑；不默认玩家盲测。 |
| gameplay-design | 根据目标、阻碍、信息和行动设计新机制；必须落实规则、反馈与测试。 |
| main-flow | 全游戏起止、节点依赖、跨场景状态与回访变化；不按节点数凑时长。 |
| narrative-branch | 按作品需要使用，保留原作结局约束，无强制多结局。 |
| narrative-npc-dialogue | 对话承担信息、关系或决策作用，避免重复交代；支持不限电影的故事来源。 |
| character-generation | 所有角色基础四向行走；直接图集或兼容母版；独立特殊动作包和接触事件。按实际游戏尺寸区分动作不可用与轻微瑕疵；可处理的透明母版无需重画。 |
| scene-generation | 背景与可玩布局一致；源图、碰撞、锚点、角色体积统一。 |
| game-state | 共用条件、原子效果、一次性奖励、版本化存档；自定义机制不能伪装为已穷举验证。 |
| interaction-generation | 绑定剧情规则与实际操作，包含成功、失败、取消与重复行为。 |
| easter-egg | 可选，不为凑内容强制加入；不能让主线依赖隐藏彩蛋。 |
| game-assembly | 确定性组装，正式资源与灰盒分离；导出无需工作台。 |
| game-reviewer | 检查机制、原作、视觉与真实证据；区分模型判断、程序检查、浏览器操作和真人体验。 |

项目副本在 `../.agents/skills/`，运行副本在 `skills/`。全局同名技能未修改；旧入口存于各技能的 references/legacy-entry-v1.md。执行 npm run skills:sync 同步和校验发布清单。

## 完整任务如何执行

Codex读取原材料和项目约定，自己安排工作并按需调用技能。可以先实现不确定的机制验证，也可以先确定不可缺少的叙事与空间；场景、人物和测试可在同一完整任务中反复修改，没有规定先后的一条流水线。

宿主提供读取技能、记录动态工作、检查、选定素材生成、灰盒/正式实测、独立审阅、最终提交和明确阻塞工具。它负责可恢复会话、资源文件、测试证据和版本指针。任何候选失败都不替换已接受版本；局部修改在新候选中进行。

工作台展示模型的工作安排和工具实际执行结果，不能把“读了一个技能”算成整部游戏完成一部分。提交最终候选后，模型回合结束，宿主再核验内容未改变才更新可玩版本。

## 框架位置

当前生产框架以 `packages/runtime/` 和 `packages/compiler/` 为准；旧版 Pixel Story Kit 独立目录已于 2026-10-31 移除，其历史来源转存于仓库根目录 `interstellar-dust/provenance/`。素材、角色、故事条件都由配置引用稳定ID；故事特有机制在候选的extensions中实现，不写入通用框架。

通用源码来源与改写范围见 provenance/README.md。第一版支持简单机制；复杂物理、战斗与复杂小游戏的制作方式留待后续设计。

## 验证边界

实际结果见 ACCEPTANCE.md。新代码有测试不等于14技能在所有题材都有效；单个完整生成样本也不证明稳定成功率。失败记录和通过证据均保留，不能用人工技术夹具替代自动生成验收。
