## 实际测试范围

- 分开启动第一块和第二块；第一块完成后停止；直接编辑生成未审阅新版本；AI 候选需采纳；未采纳或旧基础候选不能替换当前稿。
- YAML 固定来源粗剧本，保留旧版本；失败不发布候选；两轮主要修订后仍有问题保持失败。
- 生成期间拒绝并发编辑/新任务；当前问题支持补材料、回答和批次后继续；重复请求不重复生成或处理；跨项目资源访问拒绝。
- 问题在重建服务后仍存在；SSE 回放和游标续接保持问题职责、批次和状态；进度与问题分开。
- 意外中断的有效检查点恢复；损坏工作副本从宿主快照还原；失效线程新开上下文；YAML 输入副本不可恢复时只重跑 YAML；主动停止不自动恢复。
- TXT/Markdown、DOCX 正文及表格顺序、PDF 无文字页、UTF-8 解码错误；旧 Word 返回补充材料状态。未执行 OCR；复杂文档排版仍需原作核对。
- 从原执行标准实际提取并运行基础检查器，识别缺字段、重复编号和悬空引用。
- 状态模拟覆盖正常通关、不参与可选内容、物件丢失死路、重复奖励、退出继续、检查点恢复、失败、局部重开和跳过结果差异；整局重开不掩盖死路。
- 未知规则、未触达转换和探索上限不能标通过；重复键、重复转换编号、模型与 YAML 哈希/引用内容不符被拒绝。
- Agent 修改宿主检查报告副本不能发布版本；宿主权威检查报告另存于 Agent 工作区之外。

每种模拟模式默认最多 10000 个状态、250000 次转换检查；报告保留每类最多 200 条去重诊断及可复现路径。达到探索上限时明确未验证，不把截断后的结果当成全部状态通过。

## 环境与保护范围

全量测试第一次直接使用默认环境时，旧素材检查调用到了 Windows 商店的 `python3.exe` 占位程序，导致旧素材测试失败。随后只为测试进程设置 `CREATE_WORLD_PYTHON=(Get-Command python).Source`，使用本机 Python 重跑通过；未修改全局配置或旧素材代码。

构建仍有原有 `new URL('./assets/', import.meta.url)` 运行时解析提示，不阻止构建。本轮没有为消除提示修改游戏或前端资源。
