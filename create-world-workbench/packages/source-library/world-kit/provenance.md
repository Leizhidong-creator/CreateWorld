# 来源说明

World Kit v1 从 `packages/runtime` 的 `controls.js`、`input.js`、`render.js` 和 `geometry.js` 提取并整理，固定了原运行时使用的 640×360 逻辑视口、触屏交互语义、世界地图投影和最近交互目标排序。

其中摇杆交互逻辑继承 Pixel Story Kit / Beyond-The-Walls 的来源记录。原始来源和授权边界见：

- `interstellar-dust/provenance/README.md`（旧 Pixel Story Kit 来源记录的转存副本）；
- `interstellar-dust/LICENSE-NOTICE.txt`；
- `packages/runtime/controls.js` 文件头来源注释。

本目录没有改变上游代码的授权范围，也没有为原始代码重新声明开源许可证。
